# 실물 파지 자세 전용 실행파일

실행할 파일은 outputs의 **leap_measured_grip_hold.cmd 하나**다.

1. 현재 자세에서 시작한다. 사용자의 최신 요청에 따라 큐브 배치 단계나 두 번째 시작 확인을 넣지 않는다.
2. 다른 모터 프로그램을 종료하고 실행파일을 연다. 이 실행창에서 손을 뗀 뒤 SPACE를 누른다.
3. 방금 기록한 실물 유지 목표로 최대2틱/60ms씩 이동한 뒤75ms 주기로 같은 목표를 유지한다. 자동 OPEN이나 회전은 없다.
4. 종료할 때 큐브를 받친 뒤 SPACE. Q/Esc/Ctrl+C도 중단/OFF다. 기존 전체500초 한도를 유지한다.

목표는 측정각 복사가 아니라 당시 읽힌 실제 유지 목표다. 예를 들어 ID12 측정2098틱/유지 목표2124틱을 구분해 보존했다. 이미 ON이면 기존 목표에서 이어가며, 시작할 때 토크를 일부러 끄지 않는다. OFF에서 시작하면 현재 실제 위치를 먼저 목표로 넣고 안정 확인 후 켠다.

원래 PID를 보존하고450mA, 기존 전압·전류·온도·0.18rad 추종 중단, held-joint/진행 감시,200ms 안의 전체16개 읽기와 복구 확인을 사용한다. ID11 상한은 이 파일 안에서만 실제로 읽힌 목표3284틱까지 허용하며 다른 원본 제한이나 EEPROM은 변경하지 않는다. 종료 때는 OFF 확인 후 변경한 RAM 설정을 복구한다.

OFF 시작 확인은 설정 후 실제 정지 위치를 한 번 새로 읽고, 목표를 한 번만 쓴 뒤 기존4틱 범위·목표/실제1틱 차이·3회 안정 읽기 정책을 적용한다. 토크가 켜진 뒤 이동 목표의 정확한 읽기 확인과2틱 제한은 유지한다. 중단할 경우 실제값·목표값·문제 모터 ID를 로그에 저장한다.

시작 자세는 예전 모델 각도 범위만으로 거부하지 않는다. 유효한0~4095틱 측정값이면 그 시작값을 이번 실행의 경계로 고정한다. 기존 범위 밖 관절만2틱씩 안쪽으로 먼저 돌아온 뒤 기록 파지로 이동한다. 더 바깥으로 밀거나 범위 안에 들어온 관절이 다시 밖으로 나가는 목표는 거부한다. 최종 파지 목표, 전류·온도·전압·통신·추종 중단은 그대로다. 원본 관절 제한 파일과 EEPROM은 변경하지 않았다.

하드웨어 없는 소프트웨어 시험23개를 통과했다. ID11=3301틱 출발 복귀와 다른 관절의 시작 범위 예외, 잘못된 읽기값/바깥쪽 지령 거부를 포함한다. 실제로 로봇을 움직이는 시험은 사용자가 실행한다.

기존 QPC 정밀 상태 샘플러와 SDK 시간 처리를 연결했다. 이전 코드가 GetTickCount64의monotonic 시계와 QPC의perf_counter 시계를 섞어200ms 제한을 잘못 판단하던 문제를 수정했다. 실제200ms 초과 읽기는 계속 거부하며, 이동 주기의 시간 계산도QPC를 쓴다.

16:32 실행에서747개 이동 목표를 거쳐 동일한 최종 목표에 도달하고 약4.67초 유지한 뒤 사용자가 종료했다. 이어17:54 실행에서2틱/60ms 이동 후304.296초간 유지했으며, 읽기 실패0회, 최대 전류112mA, 최대 추종 오차 약0.01841rad, 최소 전압4.9V였다. 사용자가 종료했으며 모든 토크OFF와 설정 복구를 확인했다. 관절 목표의 재현 기록이며, 큐브의 정확한 방향이나 전체 회전 성공을 측정한 기록은 아니다.

## 아직 포함되지 않은 동작

새로운 배치에서 큐브 위치를 자동으로 맞추거나 다음 회전을 하는 기능은 없다. 사용자가 관찰하며 현재 관절 자세에서 기록 목표로 이동하는 자세 재현 시험이다. 큐브를 든 채 이송하는 전체 경로의 충돌 검증이나 실물 파지 성공을 주장하지 않는다.

사용자는 파지 관절 목표를 확정했다. 이 목표는 유지하며 회전 전후 연결을 수정한다. 최종 파지를 마친 큐브의 방향은 요청한90도 방향에서 우선±5도를 시험 기준으로 삼는다. 중간 회전은 정확히90도일 필요가 없으며, 이 허용치는 관절값에 적용하는 것이 아니다. 세부 기준은 cycle_acceptance.json에 있다.


최신 v5: 기준은15:38 실물 파지의 유지 목표 그대로다. 유지 중 live_state.json에 이미 읽은 실제각도가 저장되며 추가 모터 통신은 하지 않는다. 다음 회전 설계용 관찰 시에는 큐브를 기준파지로 유지하고 실행창을 열어둔다. 종료 SPACE는 관찰을 마친 뒤 누른다. 보조자는 capture_measured_grip_view_20261117.py --capture로 카메라만 열어 유지 사진과 사진 전후의 ON 표본을 저장할 수 있다. 하드웨어 동기화나 큐브 위치의 정밀 측정을 주장하지 않는다.
