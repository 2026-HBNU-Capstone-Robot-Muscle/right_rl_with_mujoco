# 최종 파지 종점과 전환 순서 수정

사용자가 명확히 한 목표는 **검지·중지를 임시 받침으로 쓰되, 마지막에는 기존 엄지·중지·약지의 아래쪽 파지로 옮기는 것**이다. 받침 위에 큐브를 남겨두는 자세를 이 목표의 완료로 세지 않는다. 중지 아래받침 정렬 단계에서 중지 윗마디도 먼저 빼서 이동 통로를 비우고, 엄지로 중지 쪽으로 옮긴 뒤 검지·중지의 아래쪽 지지로 세 손가락 파지에 적합한 위치로 옮긴다.

## 방금 실물 실행

`support_first_trial_20261112_075306_271459`는 오류 없이 모든 단계를 실행하고 사용자 SPACE로 종료했다. 토크OFF·설정복구True다. `cube_support_first_hold.jpg`에서 큐브가 손 위에 남아 있지만, 엄지·중지·약지의 기존 세 손가락 파지로 전환한 것은 아니다. 후보의 약지13/15/14/16 목표는 시작과 끝 모두2120/2304/2560/2053틱이며 변경 지령0개다. 마지막 사진만으로 전체 영상의 지지력이나 정확한 이동량을 인증하지 않는다.

기존 파일은 중지 윗마디 정리를 엄지 이동 뒤에 수행했다. 따라서 이번 결과는 받침·이동의 중간 관찰로 보존하고 최종 세 손가락 파지 검증 완료로 안내하지 않는다. 같은 중간 파일을 반복하는 대신 다음 순서를 구성해야 한다.

1. 검지·중지 아래받침 정렬과 중지 윗마디 후퇴.
2. 엄지로 충분히 중지 쪽으로 이동.
3. 엄지에 더 큰 목표를 계속 주기 전에 검지·중지 아래 지지로 이동을 넘겨받음.
4. 큐브를 세 손가락 파지에 적합한 위치로 옮기고 엄지·중지·약지의 실제 접촉으로 잡음.
5. 지지·윗단 공간·최종 왼손 파지 시 정렬과 다음 회전 연결을 확인.

## 기존 파지 자료와 새 비교

11월11일 `ring_thumb_MF_support_feedback_v2/force0.5`에는 세 손가락 접촉을 얻은 모델 참고 자세가 있다. 이 자료는 별도로 초기화된 큐브의 모델 상태이며 완성된 실물 파지 증거가 아니다. 현재 받침 종점과 해당 모델 큐브 중심은 같은 모델 좌표상 약67.499mm, 방향은52.271도 차이난다. 이 값을 실제 로봇의 이동 오차로 환산하거나 사용자가 의도한 실제 파지 위치로 확정하지 않는다. 이전 조인트 값을 그대로 넣는 두 연결은 기존 추종 기준에서 중단됐다. 원본과 실패는 `../three_finger_join/`에 보존했다.

중지 윗마디 후퇴를 먼저 한 비교는 `../clear_middle_before_push/`에 있다. 같은15mm 연구 목표에서 윗마디를 남겨둔 경우 약4.340mm 이동 후 추종 기준 중단, 먼저 빼 둔 경우 약11.975mm 이동 후 추종 기준 중단이었다. 두 경우 모두15mm 도달이나 최종 파지 통과가 아니다. 이는 먼저 통로를 비우는 순서가 모델에서 더 큰 이동을 허용했다는 증거다. 이어 `../lower_pad_lift_after_clear/`에서 중단 전의 안전한150지령만 다시 재생하고 검지·중지 아래받침으로 이동을 넘기는 구간을 검사한다. 이후 결과의 passed/stop을 먼저 확인한다.

새 비교는 실물 실행 파일에 반영하지 않았다. 기존 관절 범위·접촉 형상·450mA/PID·2틱/75ms·추종 및 건강 기준은 변경하지 않았다. 특히 토크OFF에서 읽은 약지2829틱을 새 상한이나 구동 목표로 자동 적용하지 않는다. 장치 접근·구동0.

후속 `lower_pad_lift_after_clear`의 단순 넘기기는43지령에서 추종 중단됐다. 별도v2에서 두 받침이 지지하는 동안 엄지 압박 목표를 줄이고 모델 큐브의 병진·회전에 맞춰 엄지를 따라가게 하자, 다음 받침 이동과4050상태 유지까지 통과했다(유지 지지4050/4050, 최대이동0.289mm·방향변화0.594도). 이동 구간의 큐브 전체 변화는약38.895mm였으나 이 값은 목표 파지 위치로의 도달이나 개선량을 뜻하지 않는다. 마지막 엄지·중지·약지 파지는 여전히 포함하지 않았다. 이는 큐브 상태를 정확히 아는 오프라인 모델 제어이며 실물 센서 계약이 아니다. 실물 파일은 이 후퇴·넘기기 수정 전의 중간 관찰용으로 보존한다.
