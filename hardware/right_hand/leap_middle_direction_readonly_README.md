# 중지 끝관절 방향 관측

선명한 기준/측면 사진은 이미 저장됐다. 기준 자세 한 개로는 관절의 영점과
회전 부호를 동시에 결정할 수 없다. 이번 측정은 중지 끝관절을 안쪽으로
조금 굽혔을 때 엔코더가 증가하는지 감소하는지 사진과 함께 확인하는 것이다.
10월18일07:20 관측 완료: 끝패드를 굽힌 동안 ID9가 +9.49°, ID12가 −1.67° 변했다.
따라서 이전의 `ID12=끝관절` 가정은 재검토 대상이다. 이 관측을 가정에 맞지
않는다는 이유로 실패 처리하지 않는다. 한 관절 관측으로 전체 매핑이 확정되지는 않는다.
다음 작업은 `leap_middle_joint_order_readonly_README.md`에 있다. 이 끝패드 검사를
다시 실행할 필요는 없다.

## 사용자 작업

1. 다른 모터 프로그램을 닫는다. 큐브 없이 USB·모터 전원을 연결하고 토크는 OFF.
   웹캠은 최근 측면 구도처럼 받쳐 고정한다. 중지 전체가 보이게 한다.
2. `leap_middle_direction_readonly.cmd` 실행. 현재 손 자세에서 **첫 SPACE**.
   사진 앞뒤 각도와1초 연속 촬영이 끝나 `BASELINE SAVED`가 나올 때까지 기다린다.
3. **모터 전원을 끈다.** 중지의 끝에서 두 번째 마디를 받치고 끝마디만
   손바닥 쪽으로 약10~20도 부드럽게 굽힌다. 뿌리/중간 관절은 가능한 그대로.
   저항이 크거나 다른 부품에 닿으면 힘주지 말고 Q로 종료한다.
4. 모터 전원을 다시 연결하고 토크OFF 상태에서 손을 뗀다. **두 번째 SPACE**.
   저장 완료까지 손과 카메라를 그대로 둔다. 한 창에서 끝난다.

프로그램은 PING/READ만 한다. 토크ON/OFF, 목표, 게인, EEPROM을 쓰지 않는다.
연결이 끊기거나 토크ON이 읽히면 종료한다. baseline/bent 하위 폴더에 각 사진과
앞뒤 각도를 따로 보존한다. 중도 종료돼도 완료한 기준 기록은 남는다.

각 촬영 전후3틱 이내일 때만 두 자세를 비교한다. 가장 크게 변한 ID와 그 변화가
5도 이상인지, 다른 관절이3도 넘게 바뀌었는지를 참고 정보로 기록한다. ID12로
미리 제한하지 않는다. 이 조건을 만족해도
`physical_direction_verified=false`, `calibration_selected=false`를 유지하며,
사진으로 실제 굽힘 방향을 확인한 뒤 해석한다. 수치는 구동 제한이 아닌
관측 분리 기준이다. 코드가 보정값을 자동 적용하지 않는다.

`pose_pair_readonly_.../result.json`. 정상 완료 표시는 `two_pose_pairs_saved`.
