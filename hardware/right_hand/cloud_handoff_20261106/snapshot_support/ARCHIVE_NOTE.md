# 이전 선별 스냅샷의 고유 환경 안내

이 폴더는 중복된 전체 업로드 체크아웃을 빼면서, 그 안에만 있던 환경 설정·의존성·안내·선별 범위 기록15개를 원본 바이트로 보존한 것이다. 과거 선별 스냅샷 기준의 기록이므로 현재 전체 작업 폴더를 인증하는 검증 결과로 사용하지 않는다. 현재 범위는 저장소 루트의 `RIGHT_HAND_FULL_MANIFEST.json`과 `RIGHT_HAND_SUPPLEMENT_MANIFEST.json`, 최신 진행은 본 작업 폴더의 `cloud_handoff_20261106/CLOUD_START_PROMPT.md`를 따른다. GitHub 원격 브랜치는 삭제된 상태이며 이 전달 중 자동 업로드는 하지 않았다.
