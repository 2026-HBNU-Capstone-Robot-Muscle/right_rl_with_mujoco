# 실물 SAC 큐브 회전 — 완료 기준과 남은 작업

**최신 우선 기준:** `캡스톤2 중간발표자료_v2.pptx` 슬라이드11·13–16·23.
오른손은 큐브지지와 **목표면을 위로 맞추는 연속재배향(리셋없음)**, 왼손은
상단레이어회전. 목표면기울기<0.15rad 및 위치오차<15mm를20Hz에서20스텝 유지.
아래1학기범위와 임시15도기준은 이전기록으로만 보존한다. 최신정리는
`goal_presentation_review/latest_goal_alignment.md`를 따른다.

**2026-10-15 범위 정정:** 사용자가 제공한 계획발표자료의 최종 목표는 앱 목표면
지정, Part 1 물체 이송·전달, Part 2 SAC 정밀 조작, ROS2/앱 통합이다. 아래는
Part 2 손 조작 하위 작업 계획이다. 30%를 전체 프로젝트 진척률로 사용하지 않는다.
원문 기준 정량 목표와 구현 차이는 `goal_presentation_review/goal_alignment.md` 참조.

2026-10-15. 전체 진척 약30%는 공정에 대한 주관적 추정이며, 성공률이나 남은 시간의
예측이 아니다. 실물 SAC의 안정적인 회전은 아직 검증되지 않았다.

## 목표

카메라 한 대로 상태를 추정하면서 실제 LEAP Hand가 SAC 정책으로 큐브 전체를
상하·좌우 원하는 방향으로 회전한다. 큐브의 층이 섞여도 특정 면 전체의 색 배치에
의존하지 않아야 한다. 정상 동작 중의 짧은 가림을 처리하고, 관측이 회복되면
실제 큐브 자세를 다시 확인한다. 실제 하드웨어 고장이나 지속적인 상태 불명은
계속 밀어붙이는 조건으로 취급하지 않는다.

## 확인된 성과

- 16개 모터 제어, 상태 기록, 종료 후 토크 OFF/설정 복원 구현·실기 확인.
- 기존 저장 동작으로 물리적 뒤집기가 된 사례를 사용자 확인. 반복 성공률 미확정.
- SAC 학습 및 제한된 시뮬레이션 회전 결과 존재. 실물 이식은 미완료.
- 손/큐브/받침 모델, 카메라 마커 관측 및 가림 기록 확보.
- ID12 동일 목표 시험에서 P450→600으로 잔류 오차 .123→.097rad 개선.

## 다음 순서와 통과 조건

1. **실물 관절 응답과 모델 일치 개선.** 최신 측정 로그를 사용한다. 고정 오차를
   영구적인 관절 한계로 단정하지 않는다. 필요 시 제한된 복귀 시험으로 방향에
   따른 반응을 확인한다. 새 시험은 시뮬레이션 검사 후에만 실행용으로 연결한다.
2. **경로 재검증.** 나무/유리, 손 자체 충돌, 도달 범위, 동작 지연을 함께 다룬다.
   시작 위치가 조금 달라도 통과해야 한다. 오차 임계값을 올려 통과시키지 않는다.
   빈손 완료와 큐브를 올린 회전 성공을 따로 기록한다.
3. **첫 방향 90도 회전 실기 확인.** 회전축과 목표 방향을 명시하고, 시작/종료
   자세로 검증한다. 저장된 SAC 유래 경로 재생은 중간 시험으로 표시한다.
4. **단안 관측과 실시간 SAC 연결.** ID40이 가려지는 상황을 정상적으로 다루고
   고정 ID41 기준을 검증한다. 큐브 한 면/무관측 구간의 추정 불확실성과 시간을
   기록한다. 오래된 자세를 새 측정처럼 사용하지 않는다. 관절·행동 순서,
   단위·정규화·히스토리·제어 주기를 학습 환경과 맞춘다.
5. **상하·좌우로 확장 및 반복 시험.** 한 방향의 성공을 네 방향 성공으로
   일반화하지 않는다. 시작 위치 오차, 여러 큐브 방향, 섞인 상태에서도 검증한다.

## 완료 판정 초안

- 실물에서 실시간 SAC가 목표한 네 방향 회전을 수행한다.
- 방향별10회 중9회 이상 성공, 낙하·사람의 보정 접촉은 실패로 기록한다.
- 목표 자세 오차15도 이내에서1초 유지한다. 이 수치는 제안한 검증 기준이며
  아직 달성했거나 사용자/교수님과 합의된 요구사항이라는 뜻은 아니다.
- 성공/실패별 영상 또는 자세 근거, 모터 상태, 추론·명령 전송 기록을 남긴다.
- 단순 마커 가림과 실제 통신/전원/과부하 고장을 구분해 처리한다.

## 현재 실행 상태

큐브 회전용 새 경로 후보는 모든 검증 조건을 통과하지 못했다. 적용하지 않았다.
사용자 요청으로 ID12 복귀 진단 시뮬레이션을 재개했고 모든 검사 항목을 통과했다.
기존 사용량 문제는 이번 실행에서는 해소됐다. 연결한 실행 파일은
`leap_id12_backoff_empty.cmd`이며 빈손에서 이전짧은구간+한번복귀만 측정한다.
59개 로컬 검사와 장치연결 없는파일검사를 통과했다. 다음은 사용자 빈손복귀
측정이다. 이것은 실물 SAC 뒤집기 성공이나 전체 경로 검증 완료를 뜻하지 않는다.
