# 파지 → 회전 → 같은 파지로 복귀 → 유지

최신 수정: 10:07 실행에서 복귀의 `grip_index_middle_seat` 중 ID11 추종 지연으로 중단됐고, 사용자가 중지 맨 아랫마디를 조금 올리자고 제안했다. **접기 직전에 ID12만1848→1880틱(32틱,약2.81도) 먼저 올린 뒤** 접기를 진행한다. 다른15개 관절 목표는 그대로다. 후속 원래 경로의 ID12가1880틱 이상이 되면 원래 목표를 따르므로 끝 G는 같다. 정지 기준을 풀거나 전류를 올린 수정이 아니다. 같은 실행파일을 새로 열어 시험한다. 이 높이가 실제 끼임을 해결하는지는 아직 실물 확인 전이다.

루트의 **`leap_grip_rotate_grip.cmd`**를 실행한다. 기존 `leap_grip_to_rotation.cmd`는 회전 끝 자세 유지까지 하던 파일로 그대로 보존했다.

전과 같이 큐브를 기존 파지 위치에 준비하고 손을 뗀 뒤 SPACE로 시작한다. 처음 파지 확인 안내에서 SPACE를 누르면 새 이송과 가로 회전을 이어서 진행한다. 이미 새로 가르친 이송 자세에 있으면 그 자세를 이어받고 시작 확인을 기다린다.

**회전 끝에서 큐브 지지와 복귀 시작 자리를 확인한 뒤 SPACE**를 누르면 기존 복귀 경로를 이어서 진행한다. 이 연결 단계에서 토크를 끄거나 새 목표를 다시 초기화하지 않는다. 복귀가 끝나면 원래 확정 G 목표로 약10초 정착하고 같은 목표를 계속 유지한다. 큐브를 받친 뒤 마지막 SPACE로 종료/OFF한다. 움직이는 중 SPACE/Q/Esc는 중단/OFF다.

앞부분2505개 목표는 09:44 실물 실행의 후보와 같다. 복귀는 06:44에 큐브까지 잡고 유지됐다고 확인한 후보의1417번 이후2757개 목표를 바탕으로 한다. 이번 수정에서 ID12 선행16개 목표를 추가하고 접기 구간의 ID12 높이만 앞당겨, 복귀 목표는2773개다. 나머지15개 관절의 원래 목표열은 그대로이며 끝 G 목표도 같다. 첫 복귀 목표 변화량은2틱이다. 이는 관절 목표 연결의 근거이며 실제 큐브 위치까지 동일함을 증명하는 것은 아니다. 결합 경로와 새 ID12 시점의 실물 효과는 이번 관찰 대상이다.

처음 파지와 회전 끝의 두 확인을 기다리며 나머지 구간은 이어서 움직인다. 이 구간들은 각각 실물 관찰 기록이 있지만 결합 경로의 성공이나 반복 안정성을 미리 인증하지 않는다. 자동 반복은 포함하지 않았다.

450mA/기존PID/최대2틱/75ms 및 상태·추종·전류·전압·진행·읽기 검사와 전체 ON500초 제한을 유지했다. 500초에는 확인 대기도 들어가며 시작 준비 이동까지 포함한 계획이 맞지 않으면 장치 쓰기 전 거부한다. 명목 이동 뒤 최소30초 여유를 요구한다. 이 제한을 넘기거나 이상이 생기면 기존 종료/OFF 처리가 적용된다. 정착 후에도 종료 전까지 무제한으로 유지되는 파일은 아니다.

검사10개 통과: 앞쪽 경로와 복귀의 다른15관절 목표 보존,ID12가 문제 구간 전에 올라가는 순서와 뒤쪽 원래 경로 복귀,2틱 경계,동작 사이 OFF 없음,복귀끝G일치,확인 대기 중 상태 읽기,연결부 이상 시 복귀 미진입/OFF·설정 복구,현재 이송 자세 이어받기,확인 후에도500초 제한이 초기화되지 않음,출처 변경 거부를 검사했다. 국소 정적 모델 비교에서는 기존 복귀 대비 손/받침의 추가 겹침이 없었다(`middle_root_lead_geometry.json`). 큐브 동역학이나 전체 모델 과제 통과를 뜻하지 않으며 앞선 모델·실물 차이는 그대로 보존한다.

결과는 `grip_rotation_return_trial_날짜_시각/`에 저장된다. 이번 시험의 확인 대상은 **회전 뒤 끼임이나 낙하 없이 확정 파지로 돌아와 큐브를 유지하는지**다. 두 번째 회전과 자동 반복은 후속 검증 대상이다.
