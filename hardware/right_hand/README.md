# 오른손 하부 파지 경로 변경

기존 `right_rl_with_mujoco`에서 이어진 실물 수정 작업이다. 기존 정책 파일과 배포 코드를 교체하지 않고, 하드웨어 경로 제안 모듈을 추가했다.

- 엄지 끝마디 ID1·중지 끝마디 ID9를 먼저 굽히고, 그다음 엄지 ID2·중지 ID11을 굽히는 순서를 명시했다.
- 입력으로 받은 기존 관절 제한 안에서만 경로를 만들며 목표 간격은 최대2틱이다. 450mA·기존 PID·75ms 및 기존 중단 기준을 바꾸는 코드는 없다.
- 엄지의 옆면 접촉을 앞면 모서리에서 뒤쪽으로 옮기는 벡터를 따로 계산한다. 접촉 좌표계와 이동 거리는 실물 등록값이 아닌 검토 가정이다.
- 약지 ID15의 이전 추종 중단을 반복하지 않도록 후보에만 상한을 적용할 수 있다. 장치 관절 제한을 확대하거나 중단 기준을 완화하지 않는다.

## 검증과 현재 상태

`python -B hardware/right_hand/test_tip_first_transfer_20261112.py`로 장치 접근 없이4개 소프트웨어 시험을 실행할 수 있다. NumPy가 필요하다.

이 모듈의 출력은 경로 제안이다. **모터에 바로 보내는 실행파일이 아니며, 전체 회전→유지→다음 회전 성공을 인증하지 않는다.** 실제 실험은 사용자가 시작하는 별도 Windows 실행기를 유지한다. 현재 실물은 저장 경로 재생이며 실시간 SAC 보정·새 학습·증류를 수행하지 않았다.

2026-11-12 실물 시험은 약지 접근 중 ID15 목표3076/실제2957틱, 전류281mA에서 기존 추종 기준으로 중단했다. 종료 후 토크 OFF와 설정 복구는 확인됐다. 사용자가 확인한 뒤쪽은 주황 옆면에서 흰 앞면 모서리와 멀어지는 방향이다.

새 밀기 관찰 경로는 모델에서 뒤쪽3mm 접촉을 가정한 뒤 엄지1·중지9 끝마디 → 엄지2·중지11 순서로 굽힌다. 끝마디 굽힘으로 눌리는 다른 마디의 목표를 조금 풀어 준다. 원래 범위의 절반 방향 제안에40틱 모델 목표 여유를 적용했으며, 실제 최대 굽힘까지 달성했다고 표현하지 않는다. 첫 비교는 엄지 ID2 추종 기준, 이전64틱 여유 후보는 진행 감시에서 거부됐다. 이 실패 기록을 보존했고 중단 기준은 바꾸지 않았다.

새 관찰 실행기는 마찰0.2/0.3 × 구동응답0.5/1/1.5의6조건, 빈손3조건, 실행기9시험과 고정 관절·진행 감시를 통과했다. 전체3110목표를 처음부터 초기화 없이 검사했다. 실행파일 `leap_cycle_tip_first_transfer.cmd`와 검증자료는 개인 작업본에 있다. **이번 시험에는 약지 닫힘·최종 세 손가락 파지·다음 회전이 없고, 실물 성공도 아직 아니다.** 큐브 기울기는 남아 있으므로 전체 작업이나 왼손 인계 완료로 판정하지 않는다.


이 묶음은 방금 팀 저장소에 공유했던 경로 제안 모듈·시험·검토 문서3개다. 전체 실물 실행기와 검증 자료는 별도 전달 파일에 보존한다. 자동 GitHub 업로드는 취소됐으며, 이 ZIP은 사용자가 직접 올리기 위한 파일이다. `feature/hardware` 브랜치의 `hardware/right_hand/` 경로에 배치한다. `apps/monitoring_ui`는 수정하지 않는다.
