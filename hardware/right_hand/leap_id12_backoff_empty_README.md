# ID12 빈손 복귀 진단

목적: P600 시험에서도 남은 위치 오차가 목표를 반대로 조금 움직일 때 어떻게
변하는지 측정한다. 원인이 마찰/하중/내부 제약 중 무엇인지 한 번에 확정하는 시험은 아니다.

큐브를 빼고 받침을 고정한 뒤, 다른 모터 프로그램을 닫고 실행한다.
터미널에서 SPACE 한 번으로 시작하며 Q/Esc/Ctrl+C로 중단한다.

1. 기존의 뿌리관절 회피 → 엄지 먼저 → 빈손 시작 자세 준비.
2. 지난 P600 시험과 같은 짧은40목표 구간(명목2초).
3. 목표3290틱에서1초 유지.
4. 나머지15개 목표는 고정하고 **ID12만3290→3130틱**으로32회 나누어 복귀.
   5틱씩, 명목1.6초. 더 높은 목표나 자동 재전진 없음.
5. 1초 유지 후 토크OFF 및 원래 설정 복원.

ID12 P600/I0/D150, 목표전류225mA, 측정정지250mA로 직전 성공 시험과 같다.
나머지 관절은 기존450mA/PID. 전류·전압·추종오차 중단 조건은 유지한다.
진단부 준비 이후 명목5.6초이며 통신·상태 검사 때문에 실제 시간은 늘 수 있다.

`leap_id12_backoff_empty_result.json`과 별도 타임스탬프 결과에
`approach_hold`, `backoff`, `return_hold`를 기록한다. 이전 결과는 덮어쓰지 않는다.
정상 종료여도 큐브 뒤집기나 SAC 성공으로 표시하지 않는다.

사전 검사: `sac_id12_backoff_audit_result.json`의6개 시작 사례와 준비4단계
모두 통과. 진단최대추종.113915rad, 준비포함.137175rad, 받침침투0mm.
이는 한정된 모델 검사이며 실제 토크·전류 변환/손 자체 충돌/케이블의 완전한 검증은 아니다.
모터를 실행하지 않는 파일 확인: `.runtime\python\python.exe -B leap_sac_path_empty.py --id12-backoff-check`.
