# 실제 손가락과 ID12·16의 대응 확인

**요청 취소:** 사용자가 ID12는 엄지 끝모터, ID16은 손바닥에 닿는다고
확정했다. 이 확인을 반복하지 않는다. CMD는 안내만 출력하도록 바꿨으며
장치를 열지 않는다. 아래는 준비했던 도구의 기록이다.

01:51 사진·각도 짝은16개 관절 모두 앞뒤 차이0틱으로 기록됐다. 그 각도로
재구성한 모델에서도 중지와 엄지 끝모터의 상자 간격은61.42mm다.
약지는 같은 엄지 하우징에14.93mm까지 가까워진다. 어느 경우도 실물 접촉을
정확히 재현했다고 볼 수 없다. 손가락 묶음은 과거 사용자 확인을 바탕으로
엄지1–4, 검지5–8, 중지9–12, 약지13–16으로 사용해 왔으며 아직 바꾸지 않았다.
이번 확인은 그 기록과 사진 속 접촉 손가락을 직접 연결하기 위한 것이다.

## 사용 방법

다른 모터 프로그램을 닫는다. USB·모터 전원을 연결하고 토크는 OFF로 둔다.
손가락은 현재 자세 그대로, 큐브는 없는 상태로 실행한다.

```powershell
& "C:\Users\김준서\Documents\Codex\2026-09-23\files-mentioned-by-the-user-leap\outputs\leap_finger_led_check.cmd"
```

ID12, ID16 순서로 끝모터 표시등을 켠다. 각 단계에서 불이 들어온 모터가
속한 손가락이 엄지 끝모터 하우징에 닿아 있는지 보고 **터미널에** 답한다.

- `Y`: 닿아 있음
- `N`: 닿아 있지 않음
- `U`: 불빛이 안 보이거나 구분이 어려움
- `Q`: 종료

사진을 새로 찍을 필요는 없다. 손가락을 움직이거나 분해할 필요도 없다.
답변 후 다음 ID로 넘어가며, 종료 시 이전 표시등 상태로 복원한다.
결과는 `leap_finger_led_check_result.json`과 날짜별 별도 파일에 저장한다.

## 변경 범위와 검증

제조사에서 [LED(65)는 표시등 ON/OFF용 1바이트 항목](https://emanual.robotis.com/docs/en/dxl/x/xc330-m288/#led65)으로 정의한다.
코드의 쓰기 함수는 ID12·16, 주소65, 값0·1만 허용한다. 토크·목표 위치·
전류·게인·모드·EEPROM에는 쓰지 않는다. 토크가 켜져 있으면 진행하지 않고,
다른 장치의 Secondary ID가12/16과 겹쳐도 표시등 쓰기 전에 중단한다.
표시등 쓰기 응답이 실패해도 도착했을 수 있으므로 종료 시 원래 값 복원을
시도하고 실패 여부를 기록한다. 자동 모터 재시도는 없다.

5개 오프라인 테스트로 주소65만 쓰기, 원래 LED 복원, 토크 ON 중단,
Secondary ID 중복 중단, 불확실한 쓰기 후 복원, 잘못된 요청 차단을 검사했다.
실제 모터에 연결한 실행은 아직 하지 않았다.
