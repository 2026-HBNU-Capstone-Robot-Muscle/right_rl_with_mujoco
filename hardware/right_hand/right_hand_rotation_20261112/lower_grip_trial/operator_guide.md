# 수정 파지 실물 관찰 시험

실행: `leap_cycle_lower_grip.cmd`

이전 실행파일은 보존했다. 이번 파일은 첫 회전 후 중지 윗마디를 먼저 펴고, 엄지로 이송한 뒤 검지·중지 아래받침과 약지로 지지하는 수정 경로를 관찰한다.

## 실행 순서

1. 빈손 상태에서 실행하고 첫 SPACE로 현재 OFF 자세 검사와 빈손 준비를 시작한다. 현재 자세가 저장 자세와 다르면 실행기가 새로 검사하며, 검사 거부 시 목표를 쓰지 않는다.
2. PLACE 안내가 나오면 기존과 같이 **초록 윗면·주황 손목 ID41 방향**으로 큐브를 놓는다. 손을 뗀 뒤 두 번째 SPACE를 누른다.
3. 첫 회전 → 기존 유지 → 중지 윗마디 먼저 펴기 → 엄지 이송 → 아래받침 이동 → 약지 지지 → 4.05초 유지가 자동 재생된다. 도중에 큐브가 미끄러지거나 떨어지면 Q/Esc/Ctrl+C로 중단한다. 모터 추종 기준만으로 큐브 낙하를 자동 판정하지 않는다.
4. 관찰 종료 안내가 나오면 큐브 아래를 받친 뒤 마지막 SPACE로 토크 OFF하고 종료 후 큐브를 제거한다. 실행 중 자동 OPEN/OFF는 없다.

사진 `cube_before_grasp.jpg`, `cube_grasp_hold.jpg`, `cube_lower_grip_hold.jpg`, 영상과 관절·전류·전압 기록은 새 `lower_grip_trial_.../` 폴더에 저장된다. 사용자가 별도로 로그나 사진을 다시 촬영할 필요는 없다.

## 검사 범위

- 마찰 0.2/0.3 가정 × 모델 구동 응답 0.5/1/1.5의 6조건에서 처음 배치부터 상태 초기화 없이 3194목표 전체를 검사했다. 모델 지지·추종·관절 제한·손 자체 및 받침 간섭 기준을 통과했고, 마지막 4050표본에서 엄지·중지·약지 접촉이 모두 성립했다.
- 빈손 구동 응답 3조건, 소프트웨어 9시험과 실제 실행기의 고정 관절/진행 감시 재생을 통과했다. 원본 170개 결합 소스 해시는 소프트웨어 시험에서 확인했다.
- 동일한 저장 OFF 씨드의 빈손 준비 경로가 이전 검증과 완전히 같음을 확인해 정적 201/동적 9조건 기록을 상속했다. 실물 실행 시 현재 OFF 자세를 다시 읽고 필요한 빈손 검사를 수행한다.
- 450mA, 기존 PID, 최대 2틱/75ms, 기존 건강·전류·전압·통신·추종·진행·고정 관절 중단 기준 및 승인된 최대 500초를 유지했다. 500을 다시 입력할 필요는 없다.

## 아직 인증되지 않은 부분

**이번 파일에는 다음 회전과 왼손 동작이 없다.** 윗단 회전 공간 검사는 미통과 상태로 보존했으며, 모델에서는 큐브 윗면도 바뀌고 기울기가 남았다. 따라서 이것은 수정된 세 손가락 지지의 실물 관찰 시험이고, `회전 → 유지 → 다음 회전 → 유지` 전체 동작 준비 완료를 뜻하지 않는다. 윗단 공간 합격 조건을 낮춰 통과 처리하지 않았다. 실제 왼손이나 윗단을 움직이는 명령도 포함하지 않았다.

플라스틱의 실제 마찰계수는 측정하지 않았다. 0.2/0.3은 설계 비교 가정이며, 더 낮은 0.1 가정은 첫 경로의 목표11에서 큐브가 외부 받침에 닿아 거부됐다. 재료 이름만으로 모든 마찰 조건이 검증됐다고 간주하지 않는다.

모델 접촉 보정으로 만든 명령을 저장해 재생한다. 실물에서 힘 센서를 읽거나 SAC가 실시간으로 보정하는 실행은 아니다.
