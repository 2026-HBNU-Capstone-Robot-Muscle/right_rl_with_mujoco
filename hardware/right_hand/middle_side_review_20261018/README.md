6가지 자세/가설 비교와16개 부호 조합 결과다. 이번 명목 기준에 맞춘 부호

임시 치수/평면 방향을 쓰므로 `registration_verified=false`를 유지한다.

- `overlay_0_0.png`: 원래 변환식. 초록 중지 상자가 실물 중지에서 크게 벗어남.

- `overlay_0_2.png`: 수동 명목 기준을 정확한 자세라고 가정한 가설. 검증된 보정 아님.

homing_offset은 모두0이었다. 누락된 장치 homing offset을 발견한 결과는 아니다.

분리하여 여러 사진의 같은 구조를 일관되게 설명하는 것이다.

실물 모터 명령0. 파일은 오프라인 분석이며 SAC 성공/경로 검증 결과가 아니다.
