# 기존 정책 재사용 판정: 2026-11-10

**전체 회전 → 유지 → 다음 회전 → 유지의 실물 시험 준비는 끝나지 않았다. 새 보정 정책은 실물 실행용으로 채택하지 않았다.**

원본 모델에서 접촉 계산 상한만 10회에서 50회로 바꾼 별도 모델을 만들었다. 형상, 관절 범위, 힘 한도, PID, 마찰과 동적 중단 기준은 유지했고 원본 파일도 보존했다. 같은 4,118개 명령은 50회와 100회에서 최종 물리 상태가 정확히 같았다. 이 명령열에 대한 수치 비교이며 모든 자세나 실제 로봇의 정확도를 보장하는 검사는 아니다.

기존 10회 모델의 첫 회전·유지 성공 기록은 보존한다. 하지만 50회 모델에서 기존 정책을 초기 배치부터 다시 실행한 결과는 첫 회전 4,118주기 뒤 큐브 이탈이었다. 이전 성공을 새 모델의 성공으로 이전하지 않는다.

여기서 이탈 중단은 초기 큐브 중심에서 80mm 초과 이동한 기준이다. 그래프의 공통 작업 파지 위치 오차는 다른 기준점과의 거리이므로 두 숫자를 같은 거리로 비교하지 않는다. 그래프의 수평 허용선도 최종 유지 판정용이며 전체 이동 중 항상 만족해야 하는 조건은 아니다.

짧은 창의 중간·최종 체크포인트를 별도 학습 두 번으로 세지 않는다. 이번 추가 학습은 세 번, 실제 trainer의 최종 진행 번호는 각각 10,000이다. 이전 완료 요청 분량 60,000과 이번 30,000을 합한 기록은 90,000이다. 학습 창은 중간 상태에서 초기화하며 표의 전체 평가는 초기 배치 뒤 상태 초기화가 없다. 학습 창의 점수 개선·중단 없음은 전체 성공이 아니다. 추론 이식은 NumPy/JAX 일치를 확인했지만 증류 완료가 아니다.

현재 정책은 원래 기준 궤적의 각 목표에 **최대 ±0.01rad, 약 ±0.573도/±6.519틱**을 더하는 잔차 정책이다. 이후 실제 명령은 기존 범위와 **주기당 최대 2틱, 75ms** 제약으로 선택한다. 기준 궤적 주변의 제안 범위와 실행 속도 제한은 다르다. 속도 제한 때문에 실제 지령이 제안 범위를 잠시 따라가는 구간도 있다.

별도로 지지를 확인한 초기화 약지 후보 한 개는 기존 첫 파지와 약지 네 지령이 약 671/−518/−1127/585틱 다르다. 이 후보가 유일한 파지이거나 그 이동량이 최소 필수라고 입증한 것은 아니다. 다만 작은 잔차 정책을 연결하는 것만으로 그 후보의 큰 접촉 전환까지 구현했다고 볼 수는 없다. 원본 108차원 정책과 110차원 기준 궤적+잔차 정책도 구분한다.

새 학습을 계속 늘리는 것만으로 해결된다는 근거는 없다. 다음 준비는 수렴 조건에서 기준 동작의 접촉 모드와 잔차 제어 범위를 함께 검토하는 일이다. 작은 보정으로 가능한 회전과 관절 지령을 누적해 접촉을 바꾸는 재파지를 구분하고, 입력/행동 계약을 바꾸면 별도 정책과 검증 기록으로 관리해야 한다. 이 결과가 기존 정책 전체의 무용성이나 새 학습의 필수성을 입증하지는 않는다.

실물 전체 시험 전에 남은 근거는 다음과 같다.

1. 50회 모델에서 초기 배치부터 첫 회전과 공통 하부 파지 유지 통과.
2. 그 실제 끝 상태에서 약지로 하중을 넘기고 다시 작업 파지를 유지하는 경로 통과. 직접 초기화한 끝 자세의 유지와 구분한다.
3. 상태 초기화 없이 다음 90도와 유지까지 연결.
4. 배치·구동·관측 오차 및 실물 카메라와 정책 좌표계의 등록 검증.

원래 실행 결합 파일 170개와 팀 캐시 소스 57개는 보존했다. 모터·카메라를 열지 않았고 원격 저장소와 UI도 변경하지 않았다. 현재 사용자의 재연결·촬영·큐브 제거 확인을 요구하지 않는다.
