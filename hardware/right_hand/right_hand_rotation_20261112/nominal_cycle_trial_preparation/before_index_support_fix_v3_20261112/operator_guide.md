# 전체 연속 동작의 명목조건 관찰 시험

**최신 ID16 보정v2:** 재시도055048도 같은ID16 진행 오류였다. 실제2145틱 정체/기존목표2209틱을 근거로, 이번 경로의ID16목표만 최대2177틱으로 낮췄다. 다른15모터 목표·2틱/75ms·진행 감시·관절/건강 기준과 최대500초 승인은 유지한다.691개 지령의ID16만 변경했다. 새명목 모델에서5089목표를 처음부터1ms검사해 두 회전·두 유지와 최종180도 오차3.778도를 통과했다. 큐브 없는 손3조건의 기존 미세접촉 실패는 남아 있으며 실물 수정 효과는 아직 미확인이다.

기존 실행창을 닫고 루트의 같은 `leap_cycle_nominal_two_turns.cmd`를 새로 실행한다. 제목에 **ID16 보정v2**가 보이는지 확인한다. 토크OFF 상태에서 아까처럼 중지 끝을 조금 편 뒤 시작하면 되고, 빈손 진입은 새 실제값으로 다시 검사한다. 나머지는 같은 SPACE 절차다.500입력을 다시 요구하지 않는다.

**이전 버전의 실행 기록:** ID16 진행 감시 중단과 중지 복귀 경로 검사 차단은 [실물 검토](../nominal_cycle_actual_review/REVIEW.md)에 남겼다. 이전 버전 그대로의 반복 대신 위 보정v2를 사용한다. 아래는 공통 시험 절차다.

**승인 갱신:** 사용자가 채팅에서 “상한 올려도 되”라고 승인해 이 후보의 최대500초 범위를 반영했다. `500`을 다시 입력할 필요 없이 기존 SPACE 절차로 시작한다. 아래 명목조건·손만검사 실패와 실물 미검증 범위는 그대로다. 보조자는 모터를 구동하지 않았다.

**실행 파일: 루트의 `leap_cycle_nominal_two_turns.cmd`.** 기존 stage1/stage2 파일은 바꾸지 않았다.

이 파일은 처음 배치부터 회전→윗단 공간을 비운 유지→다음 회전→유지를 연결한 저장 모델5089목표를 재생한다. 이번에 실물에서 관찰한 stage2의 끝에 기존 다음 경로를 붙이는 방식과 다르다. 첫1417지령이 이전 실제 시험과 같다고 주장하지 않는다. 실물 성공·정밀90도·오차 내성은 아직 검증 전이다. 저장 경로 재생이며 새SAC 학습·실시간SAC·증류가 아니다.

## 실행 전에 확인할 범위

- 보존된 명목 모델은381675개의1ms 상태에서 기존 관절·자기접촉·받침·추종·지지 기준을 검사했고 두 회전과 두 유지를 통과했다. 마지막180도 목표 오차는 3.778도, 다음 추가 수평 회전은 91.454도다. 이는 실제 측정값이 아니다.
- 작은 초기 배치·마찰 변화에서 실패했던 기록은 남아 있다. 모든 조건에 안전하거나 성공한다고 인증하지 않는다.
- 큐브를 비활성화한 손 자체의 구동0.5/1/1.5 비교3개는 약0.00025~0.0016mm 모델 자기접촉으로 실패했다. 큐브가 있는 명목 모델의 통과와 구분한다. 이 실패를 통과로 바꾸거나 자기접촉 한계값을 확대하지 않았다.
- 빈손 준비 경로 정적 201조건·동적 9조건과 소프트웨어 9검사는 통과했다. 현재 실제 시작각은 사용자가 실행할 때 다시 읽고 그 진입을 새로 검사한다.
- 저장 시작 기준 지령 시간은 447.075초(약7분27초)다. 기존300초 제한 안에 들어오지 않아 **이 시험에 한해 최대500초를 제안**한다.450mA/기존PID/2틱/75ms 및 전압·전류·온도·추종·통신 중단 기준은 동일하다. 모델0.15N·m를450mA의 환산으로 쓰지 않는다.

## 순서

1. 큐브를 손 밖에 두고 `.cmd`를 실행한다. 최대500초 범위는 채팅에서 이미 승인돼 `500`을 다시 입력할 필요가 없다. 기존 SPACE 절차로 진행한다.
2. 기존과 같이 **첫 SPACE**로 빈손 시작 검사·준비. 실제OFF값에서 경로를 새로 검사한 뒤 동작한다.
3. **PLACE가 뜬 뒤** 받침 자리에 초록면 위/주황면 손목ID41 방향으로 큐브를 놓고 손을 뗀 다음 **두 번째 SPACE**. 이 후 두 회전과 두 유지가 이어진다. 중간에 큐브를 다시 놓거나 관절을 손으로 옮기지 않는다. 두 유지의 지령 길이는 각각4.05초다.
4. 마지막 관찰 종료 안내 뒤 큐브 아래를 받치고 **마지막 SPACE**로 OFF. 설정 복구와 종료 확인 뒤 큐브를 뺀다. 자동OPEN은 없다. 이상하면 기존 Q/Esc/Ctrl+C로 중단한다.

최대500초 범위의 사용자 채팅 승인을 기록했다. 승인 기록만으로 모터가 움직이지 않으며 실제 움직임은 사용자의 SPACE가 시작한다. 기본 검사는 장치를 열지 않으며 승인 뒤500입력을 다시 요구하지 않는 것도 소프트웨어에서 확인했다.

결과는 `nominal_two_turn_trial_날짜_시간/result.json`에 저장된다. 첫 유지 `cube_first_cycle_hold.jpg`, 마지막 유지 `cube_second_cycle_hold.jpg`를 확인한다. 프로그램 완료를 목표 달성으로 자동 판정하지 않는다. 손 위 지지에는 손바닥·뿌리·하우징 받침도 포함한다. 실제 두 회전과 유지가 확인된 뒤 같은 조건의 반복·배치 차이를 별도로 평가한다.
