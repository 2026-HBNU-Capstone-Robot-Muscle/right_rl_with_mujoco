## 2. 목표와 현재 실행 방식

목표: **큐브 전체 회전 → 윗단 공간을 비운 하부 파지 유지 → 다음 회전 → 파지 유지**.
최종 작업 파지는 엄지·중지·약지이며, 검지·중지의 아래쪽 받침은 큐브를 옮기는 중간 단계다.
왼손은 오른손이 지지하는 동안 윗단을 파지·회전·해제하는 역할이다.

현재 실물 실행 방식은 모델에서 검토한 정수 틱 경로를 위치 제어기로 재생하는 방식이다.
기존 정책, SAC 추가 학습, 관측·추론 이식 및 모델 비교 자료는 별도 폴더에 함께 보존되어 있다.

## 4. 실물 설정과 작업 규약

- 장치: LEAP 오른손, XC330-M288 16개. 원래 PC의 최근 포트는 **COM7**, 통신은 **1 Mbps**.
- 구동 기준: **450mA, 기존 PID, 최대 목표 간격 2틱, 75ms**, 기존 전압·전류·통신·추종·진행 감시 유지.
- 모터 ID, 손끝→손바닥: 엄지 `1,2,3,4`; 검지 `5,7,6,8`; 중지 `9,11,10,12`; 약지 `13,15,14,16`.
- 시뮬레이션 순서: `(8,6,7,5,12,10,11,9,16,14,15,13,4,3,2,1)`; `qsim=(ticks-2048)*2π/4096`.
- 큐브 55mm, 단단한 플라스틱 손끝. 현재 받침은 **본체 아래 20mm 책, 원래 받침 유리 6mm** 기록을 기준으로 한다.
- 실물 시작은 사용자의 `.cmd`와 SPACE. 첫 SPACE는 빈손 검사·준비, PLACE 안내 후 큐브 배치와 두 번째 SPACE, 관찰 종료 후 큐브를 받치고 마지막 SPACE로 OFF.
- 현재 배치 안내: **초록 위, 주황 면은 손목 ID41 방향**. ID41 마커 약27mm, 큐브 마커 약10.7mm.
- 원본 170개 파일의 결합 검증을 보존한다. 경로나 연결부를 바꾸면 영향받는 검증·해시를 갱신한다.

## 마지막: 미완료·실패 기록과 이어서 할 일

1. **최신 세 번은 구동 전 검사에서 종료.** `tip_first_trial_20261112_173345_707995`, `_173745_907847`, `_173936_071900`은 모두 `screen_current_pose`에서 종료했고 모터 쓰기 0회다. 새 밀기 동작의 실물 결과로 세지 않는다.
2. **초기 간섭 예외 적용 후 실물 확인이 남아 있다.** 엄지 끝–검지 뿌리 모델 겹침은 명목 0.936mm이며 저장된 빈손 경로에서 초기값을 넘지 않고 OPEN 12번째 목표에서 사라졌다. 교란 정적 조건의 최대값은 약1.699mm다. 사용자는 이 초기 모델 겹침을 허용하라고 요청했다. 2026-11-13 해당 쌍·빈손 구간·초기값 이하 조건으로 반영했고, OPEN 48목표 이내 분리·배치 유지 때 겹침0을 요구한다. 입력 교란을 포함한 초기 모델 깊이 상한은1.75mm다. 저장 자세3개에서 각각201정적/9동적 조건, 실행기18시험과 예외 처리7시험을 통과했다. 기존 모터·적재 경로·형상·힘 계산은 유지했다. 새 실물 확인은 다음 작업이다. 실제 부품 간격을 측정한 값으로 쓰지 않는다.
3. **직전 실제 전환 실행의 중단.** `lower_grip_trial_20261112_162806_610535`는 약지 ID15 목표3076/실제2957틱, 281mA, 추종오차0.183rad에서 종료됐다. OFF와 설정 복구를 확인했다. 접촉 위치와 밀기 순서에 대한 사용자 수정이 끝마디 우선 후보에 반영됐으며, 그 효과의 실물 확인이 다음 단계다.
4. **최종 엄지·중지·약지 파지, 윗단 공간, 그 파지에서의 다음 회전은 연결·검증이 남아 있다.** 현재 관측 시험에는 약지 닫힘과 다음 회전이 들어 있지 않다. 기존 READY는 제한된 시험 파일의 준비 기록이며 전체 동작 완료를 뜻하지 않는다.
5. **정책 평가의 범위를 구분한다.** 원본108차원 정책과 로컬110차원 기준 궤적+SAC 보정 정책은 별개다. 11/9~10 기록에는 SAC 추가 학습 요청 분량 합계90,000환경 스텝과 별도 모방학습15,000갱신이 있다. 접촉 계산10회 모델의 좋은 결과가 50/100회 조건에서는 재현되지 않은 기록이 있으므로 과거 모델 성공을 현재 실물 성공으로 쓰지 않는다. NumPy 이식을 증류 완료로 부르지 않는다.
