앞으로 파지 작업은 이 실물 자세를 우선 기준으로 삼는다. 독립 초기화한 모델 후보의 유지 시간만 늘리는 작업을 우선하지 않는다.

사용자가 현재 파지의 윗단 회전 공간이 널널하다고 직접 확인했다. 큐브 유지와 윗단 공간은 이 사용자 실물 관찰을 기준으로 삼으며 같은 확인을 반복 요구하지 않는다. 큐브 자세·실제 접촉 위치·공간의 정량 치수는 아직 측정하지 않았다. 이 관절값에 큐브 위치를 임의로 맞춘 모델 결과를 실물 파지 검증으로 설명하지 않는다.

다음 작업은 실제 회전 끝에서 이 파지로 들어오는 전환과, 이 파지에서 다음 회전으로 넘어가는 경로를 준비하는 것이다. 사용자는 필요한 중간 자세를 직접 맞춰 도와줄 의사를 밝혔다. 보조 작업으로 해결되지 않는 특정 구간이 확인되면 어느 손가락을 어디로 옮기는 자세가 필요한지 구체적으로 요청한다. 막힌 구간을 특정하지 않은 채 새 파지나 임의 자세를 반복 요청하지 않는다. 자동 구동 파일이나 새 정책은 이번 기록에서 생성하지 않았다.
