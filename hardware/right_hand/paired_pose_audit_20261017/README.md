# 01:51 사진·각도 짝 재구성

원본: `pose_pair_readonly_20261017_015118_321695/result.json` 및 `paired_photo.png`.
16개 위치의 앞뒤 차이는 모두0틱, 모든 토크 OFF·장치 오류0으로 기록됐다.
이는 읽기 전후 정지 조건이며 하드웨어 동기 촬영이나 중간 왕복 움직임
부재의 증명은 아니다.

이전19:39 기록과 중지는 ID9/11 변화0도, ID10 +0.176도, ID12 +0.879도다.
엄지 ID4는 -14.238도 달라졌다. 새 사진에는 새 각도만 사용했다.

현재 매핑과 영점 그대로 재구성한 `fresh_encoder_views.jpg`를 만들었다.
중지 전체 상자와 엄지 끝모터 주변 상자의 최소 간격은61.424mm다.
끝패드 `th_tip`를 제외한 하우징 상자만 비교한 결과:

| 모델 손가락 | 엄지 하우징까지 최소 거리 |
|---|---:|
| 검지 |63.693mm|
| 중지 |61.424mm|
| 약지 |14.929mm|

약지가 가깝다는 것이 실제 약지의 접촉이나 ID 교환의 증명은 아니다.
단순히 사진 속 손가락의 이름만으로 중지에 큰 영점 보정을 적용하기 전에
실제 ID를 시각적으로 연결할 이유다. 기존 사용자 확인에 기반한 묶음은
바꾸지 않았다. 독립 OBB 거리 계산을 사용했고, 아직 CAD 실물 표면의
정확한 거리나 동적 충돌 검증으로 해석할 수 없다.

새 사진의 ID40을 검출기로 읽지 못해 마커 기반 투영은 생성하지 않았다.
사진·각도 짝 자체는 유효하며 마커 때문에 재촬영을 요구하지 않는다.
조건부 마커 좌표로 내보낸 `geometry.json`의 좌표는 보정 완료 값이 아니다.

사용자가 ID12는 엄지 끝모터, ID16은 손바닥에 닿는다고 확인했다.
표시등 요청은 취소하고 CMD도 장치를 열지 않도록 바꿨다. 같은 확인을
반복하지 않는다. `confirmed_contacts.json`에서 약지 끝–손바닥 상자 겹침이
확인되며, 중지–엄지 간격만 남는다. 실제 목표·영점·전류·게인·경로는
변경하지 않았다.

`collision_filters.json`: 관련 충돌 형상은 모두 contype/conaffinity=1이고,
기존 엔진이 약지–손바닥 접촉을 이미 감지한다. 꺼진 충돌 필터가 원인은
아니다. 현재 q를 강제로 대입한 정적 검사이므로 약2.44mm 모델 겹침을 실물
침투량이나 물리적으로 안정된 자세로 해석하지 않는다.

중지 영점 차이를 구분하기 위한 그림 `middle_reference_upright.jpg`를
준비했다. 손바닥에 수직으로 곧게 세운 **하나의 자세**를 두 방향에서 보인다.
다른 손가락을 숨긴 설명 그림이며 실물 모터 명령은 생성하지 않았다.
실제 측정 안내는 상위 폴더 `leap_middle_reference_README.md`에 있다.
