# 세로 회전 뒤 새 엄지 밀기·후퇴로 확정 파지

새 실행파일은 [leap_vertical_direct_grip.cmd](../../../leap_vertical_direct_grip.cmd)다. 기존 `leap_vertical_rotate_grip.cmd`는 긴 복귀 경로를 보존한 파일이므로 이번 새 동작은 위 새 파일로 확인한다. 새 직접 복귀는 실물 확인 전이다.

1. 큐브를 확정 파지 자리에 준비하고 손을 뗀 뒤 실행창에서 SPACE. 시작 때는 **엄지를 먼저 파지 위치로 내림 → 끝마디 준비 → 검지·중지와 나머지 받침을 G로 맞춤** 순서다. 시작값의 범위 초과분은 그 전에 기존 범위 안쪽으로만 복귀하며 제한을 넓히지 않는다.
2. 확정 파지 확인에서 SPACE로 기존 세로 회전. 회전 끝에서 큐브가 받쳐져 있으면 SPACE로 새 직접 복귀를 시작한다. 큐브를 손으로 재배치하지 않는다.
3. **검지·중지를 기존 낮은 받침 자세로 맞춤 → 엄지로 약지 쪽으로 밀기**. 큐브가 최종 파지 자리에 왔는지 확인하고 SPACE. 불일치/끼임이면 받친 뒤 Q로 종료한다.
4. **새로 기록한 엄지 후퇴**. 큐브에서 엄지가 비켰고 큐브가 받쳐져 있으면 SPACE.
5. **엄지를 먼저 파지 위치로 내림 → 검지·중지 끝마디 준비 → 나머지 받침을 G로 닫기**. 엄지를 먼저 내릴 때 약지는 엄지 이동 길을 함께 비키며,검지·중지는 이 구간 내내 유지한다. 아래쪽 파지를 확인하고 SPACE로 계속 유지한다.
6. 같은 G로 계속 유지한다. 큐브를 받친 뒤 SPACE로 종료/OFF한다. 움직이는 중 SPACE/Q/Esc는 중단/OFF다.

전체 실행·확인 대기·최종 유지의 시간 제한은 없다. 전류450mA/PID/최대2틱/75ms와 전압·온도·추종·진행·유지 관절·통신 이상 중단은 그대로다. 중간 OFF나 자세 초기화는 없다.

엄지 ID1/2/3/4 유지 목표는 밀기2983/2673/2260/2035틱,후퇴2420/2954/3017/2092틱이다. 각각 두 번 읽은 실제값 차이는0/최대1틱,목표 오차는최대3/2틱이었다.16개ON/오류0을 확인했고 기록 작업은 PING/READ뿐이다. 모터 쓰기·토크변경은0이다. 사진은 거의 검어 큐브 접촉을 시각적으로 판정하지 못했다. 새 수동 기록의 다른12관절 전체를 새 목표로 복사하지 않았다.

모델에서 세로 끝의 세워진 검지 모양을 그대로 둔 엄지 단독 밀기는 약9.86mm 간섭이 있어 채택하지 않았다. 기존121158 받침의 검지·중지8관절을 먼저 맞추는 이송 준비는 유지한다. 새 복귀2863목표는 받침523/엄지밀기435/엄지후퇴379/**엄지선행·약지비킴448**/끝마디405/나머지받침673이다. 엄지 밀기로 큐브 위치를 옮기는 단계와,확정 파지로 닫는 단계를 구분한다. 기존 세로3196목표는 그대로 보존했고,전체6059목표의 끝 G도 같다. 기존600목표 손바닥 이송은 빠졌지만 새 자세 이동 거리가 있어 전체 소요시간이 크게 줄었다고 주장하지 않는다.

11월23일 순서 수정은 `vertical_direct_grip_trial_20261118_204744_702191`의 시작 파지 중단을 기준으로 했다. 이전에는 다른 손가락을 G로 닫은 뒤 엄지를 넣다가 ID2 목표43틱 진행 대비 실제 진행0틱으로 중단됐고 OFF·복구가 완료됐다. 기존 후보와 코드는 `before_thumb_first_20261123/`에 보존했다. 회전 후 엄지 선행을 약지 고정 상태로 적용한 시안은 엄지·약지 약14.73mm 모델 겹침이 있어 채택하지 않았고,약지 동시 비킴으로 해소했다. 시안 진단도 보존했다.

소프트웨어10검사와 장치 없는 실행 검사를 통과했다. 기존 세로/끝 G 보존,엄지 기록값 일치,엄지 밀기·후퇴 중 지지12관절 유지,시작 및 복귀의 엄지 선행,중간 OFF 없음,600초씩 확인 지연에도 진행,상태 이상 시 후속 차단/OFF·복구,멈췄던 시작값의 전체 가상 실행을 확인했다. ID2를 가상으로 고정한 경우에는 검지·중지 진입 전에 기존 진행 중단과 OFF·복구가 적용됐다. 정적 비교에서 기존 경로와 기록 시작 자세보다 새 겹침은 없었으며,기존 엄지·손바닥/마운트와 옛 받침 모델 불일치는 남는다. 형상 삭제나 새 관절범위 확대는 없다. 큐브 동역학과 수정 파지의 실물 성공을 인증하는 검사는 아니다.

결과는 `vertical_direct_grip_trial_날짜_시각/`에 저장한다. 먼저 엄지 밀기 뒤 실제 큐브가 최종 파지 자리로 오는지와,엄지 후퇴/파지 중 큐브가 유지되는지를 확인한다.
