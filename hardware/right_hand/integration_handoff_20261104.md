# 양손 프레임 결합 전 인계

현재 단계: 프레임 결합과 높이 조절을 진행하면서 오른손 제어를 계속 보완한다. 오른손의 회전 후 최종 고정이 완성됐다는 뜻은 아니다.

## 바로 공유할 내용

> 오른손은 현재 받침과 본체의 상대 위치를 최대한 유지해서 고정하고, 받침 아래쪽에서 전체 높이를 조절하는 방식으로 맞추겠습니다. 준비 자세와 큐브 배치는 실물에서 확인했고, 회전 후 안정적으로 고정하는 동작은 보완 중입니다. 말씀하신 바닥 기준 약16cm가 큐브 중심인지, 윗층을 잡는 손끝 접촉점인지 확인 부탁드립니다. 같은 바닥을 기준으로 현장에서 위치를 맞추고, 우선 현재 프레임 방향에서 간섭을 확인하면 좋겠습니다.

## 조립할 때 정할 기준

1. 양쪽 모두 같은 조립 바닥면에서 높이를 잰다. 각 손목이나 서로 다른 받침 밑면을 기준으로 잰 값을 직접 비교하지 않는다.
2. 왼손의16cm 기준점이 큐브 중심, 큐브 바닥, 실제 윗층 접촉점 중 어디인지 확인한다. 큐브 한 변은55mm이므로 중심과 윗면만 해도27.5mm 차이가 있다.
3. 오른손 본체와 바로 아래 받침 사이의 높이, 앞뒤 위치를 유지한다. 전체 높이를 바꿀 때는 이 조합 아래에서 조절하는 쪽을 먼저 검토한다. 손가락 뒤쪽 몸통과 받침의 여유가 달라지면 복귀 경로 검토도 달라진다.
4. 현재 프레임 외형48×48×40cm, 프로파일40mm라는 정보만으로 손목 배치와 실제 내부 여유를 확정할 수는 없다. 우선 맞대어 보고 손가락 전체 이동 공간과 큐브 접근을 확인한 뒤 프레임 회전 여부를 정한다.
5. 운반과 받침 재배치는 모터 전원을 끈 상태에서 한다. 고정은 손가락, 모터 축, 케이블이 아니라 본체/장착부를 통해 잡는다. 최종 조립 후에는 현재 각도 읽기와 변경된 받침 조건 확인부터 재개한다.

## 가져갈 것과 현장에서 기록할 것

- 오른손 본체, 현재 사용 중인 받침 구성, 기존5V 전원, USB 어댑터, 큐브, 웹캠과 노트북.
- 양쪽 공통 바닥 기준 큐브 중심 높이와 윗층 접촉 높이. 수치를 맞추려면 줄자나 자를 준비한다.
- 고정된 오른손 본체의 앞뒤 방향과 받침 앞끝 위치가 함께 보이는 사진 한 장. 새로운 기준을 남기는 목적이며 같은 정지 촬영 프로그램을 반복할 필요는 없다.
