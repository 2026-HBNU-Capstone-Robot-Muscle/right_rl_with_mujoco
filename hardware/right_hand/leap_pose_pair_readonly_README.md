상태여야 한다. 이 프로그램은 토크를 켜거나 끄지 않는다. 손가락은 현재
자세 그대로 두고 큐브를 올리지 않는다.

후 저장 완료까지 카메라와 손을 그대로 둔다. ID40/41 인식은 실행 조건이

1. 직접 SDK PING/READ로16개 모터를 검사한다. 토크 ON·장치 오류·통신

## 한계와 검증

카메라 시간은 드라이버 read 이후 시간이다. 엔코더도 순차 읽기이므로
정밀 하드웨어 동기화가 아니며, 앞뒤 값이 같아도 그 사이 왕복 움직임까지
검출할 수는 없다. 따라서 손과 카메라를 정지시켜야 한다. 사진·각도 짝의
확보는 카메라 외부 좌표나 관절 영점의 보정 완료를 의미하지 않는다.

오프라인 테스트는 새 프레임만 저장하는 순서, 프레임 유실, 위치 변화,
누락 모터, 토크 조건 및 기존 검사 함수의 SDK 읽기 전용 호출을 확인한다.
실제 장치를 연 검사는 사용자 실행 전에는 하지 않았다.
