# 최종 파지 모양만 취해 유지하기

2026-11-16 시작 범위 수정: 실물에서 읽은 ID8=1818, ID12=1823, ID16=1842틱을 시작 자세로 허용한다. 이 파일에 한해 시작 하한을 각각 1814/1819/1838틱으로 두며, 처음에는 기존 범위 쪽으로만 천천히 복귀한다. 다른 관절의 허용 범위와 하드웨어 설정은 유지한다. 현재 시작 기준 이동 시간은 약 1분 50초다.

임시 받침은 사용자의 근사 요청에 따라 모델에서만 별도 가정했다. 책20mm·유리6mm 및 기존 받침 두께는 유지하고, 옆 폭은 손 본체 CAD 폭+양쪽15mm, 아래 받침 앞끝은 본체 앞끝까지, 책 앞끝은 기존 사진 가설보다10mm 뒤쪽으로 가정했다. 충돌 형상과 접촉 힘은 남아 있다. **이 치수들은 실측값이 아니며 실제 간섭이 없다는 인증이 아니다.** 이 근사가 적용되는 범위는 현재 빈손 자세 확인 명령뿐이다.

실행: outputs 폴더의 `leap_final_grip_pose.cmd`.

이 파일은 **빈손으로**, 회전 후 사용하려는 엄지·중지·약지 아래쪽 파지의 목표 손 모양만 확인한다.

1. 큐브를 손에서 빼고 실행한다. 카메라와 로봇은 기존 원래 PC 연결을 사용한다.
2. 터미널에서 첫 SPACE: 현재 토크 OFF 관절값을 읽고, 그 시작 자세에서 경로를 검사한다. 검사 중 관절을 움직이지 않는다.
3. 3초 예고 뒤 빈손 준비 자세를 거쳐 최종 손 모양으로 천천히 이동한다. 저장 시작 자세에서는 약 103초이며 실제 시작 자세에 따라 달라진다.
4. `FINAL POSE HOLD`가 나오면 같은 목표각을 계속 유지한다. 새 목표 쓰기 없이 상태를 계속 읽는다.
5. 터미널 SPACE로 종료한다. Q/Esc/Ctrl+C도 중단한다. 종료 시 토크 OFF와 기존 설정 복구를 확인한다.

자동 OPEN, 전체 회전, 큐브 배치 대기는 없다. 전체 토크 ON 최대 500초이며, 자세 이동에 쓴 시간도 포함된다. 저장 시작 기준 유지 시간은 약 6분 30초 이내다. 전류 450mA, 기존 PID, 목표 간격 최대 2틱/75ms 및 기존 전압·온도·통신·추종·관절 제한을 유지한다.

목표 출처는 `ring_thumb_MF_support_feedback_v2/force0.5/end_state.npz`의 실제 모델 관절 자세(qpos)이다. 큐브를 밀기 위한 ctrl 값은 복사하지 않았다. 빈손에서 엄지 끝과 중지 밑부분의 여유를 위해 ID3만 +4틱(약 0.352도) 보정했다. 원래 자세와 보정량은 `manifest.json`에 별도 기록했다. 관절 제한이나 충돌 기준은 넓히지 않았다.

`review.json`: 시작 준비와 최종 자세까지 전체 경로의 모델 검토. `software_verification.json`: 장치 없는 실행·중단 시험. 실행 후 `final_grip_pose_날짜_시간/result.json`에 실제 결과와 유지 중 사진이 저장된다. 이 파일들은 현재 로컬에 준비하며 자동으로 GitHub에 반영되지 않는다.

## 아직 확인하지 않은 것

실제 큐브를 잡는 접촉 위치·지지력·윗단 공간은 검증하지 않았다. 이 실행 중 큐브를 넣지 않는다. 회전→파지 전환과 다음 회전도 포함하지 않는다. 모델 검사 통과는 실물 파지 성공을 뜻하지 않는다. 기존 통신 오류 등이 재발하면 같은 중단 기준으로 OFF한다.

이전 시작 자세의 약한 구동 가정에서 ID8 처짐으로 멈췄던 기록과 변경 전 증거는 `before_passive_roots/`에 보존했다. 수정 후 감시 재생 결과는 `runtime_guard_review.json`, 전체 경로 검사는 `range_fix_verified/` 및 활성 `review.json`을 확인한다. 새로 허용한 수동 시작의 모델 연성 관절 한계에는 초기 정지·복귀 구간만 2틱의 수치 잔차를 두었다(ID12 모델 잔차 1.0542틱 확인). 실제 목표·시작 허용 범위·추종 중단 기준에는 이 잔차를 적용하지 않는다. 새로운 시작 자세나 임시 받침의 실제 물리 구동 성공은 아직 확인하지 않았다.
