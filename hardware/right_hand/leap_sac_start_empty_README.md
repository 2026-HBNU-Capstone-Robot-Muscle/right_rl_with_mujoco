# 새 SAC 시작 자세의 빈손 확인

이 실행은 시뮬레이션에서 사용한 새 시작 자세가 실제 받침과 간섭하는지 확인합니다. 큐브 뒤집기나 SAC 정책은 실행하지 않습니다.

1. 큐브를 빼고 손 본체를 고정합니다. 다른 모터 프로그램을 닫고 USB와 모터 전원을 연결합니다.
2. PowerShell에서 실행합니다.

```powershell
& "C:\Users\김준서\Documents\Codex\2026-09-23\files-mentioned-by-the-user-leap\outputs\leap_sac_start_empty.cmd"
```

3. 해당 터미널에서 SPACE를 한 번 누릅니다. 3초 후 검지·중지·약지의 뿌리 관절을 받침에서 벗어나는 방향으로 먼저 이동하고, 새 시작 자세로 이동합니다. 약 2초 유지 후 토크를 끄고 기존 설정을 복원합니다. 큐브는 끝까지 올리지 않습니다.
4. 모터 하우징이 유리/나무 턱에 닿았는지 관찰하고, 종료 로그를 알려주세요. Q/Esc/Ctrl+C는 중단합니다. 접촉·걸림이 보이면 Q로 중단하세요.

전류는 기존 시퀀스의 450mA, P600/I0/D200이며 ID8/12/16은 P450/D150입니다. 이번 검사에서는 전류를 올리지 않습니다. 카메라와 마커는 필요하지 않습니다.

결과는 `leap_sac_start_empty_result.json`과 시간별 기록에 저장됩니다. 새 시작 자세의 기준은 SHA256으로 고정되어 있으며, 파일 검증과 모의 버스 종료/복원 테스트를 통과했습니다. 실물 실행은 아직 하지 않았습니다.
