## 실제 실행한 오프라인 비교

`audit_middle_motor_order.py`를 WSL MuJoCo에서 실행했다. 네 중지 ID의24가지
순서를, 새 전·후 자세/03:26 기준 자세/10월17일01:51 접촉 자세에 각각 대입했다.
모든 후보에서 공통 변환 `ticks * 2π/4096 - π`를 사용했다. 큰 영점 오프셋을
추가하지 않았다. 18가지가 네 자세 모두 모델 각도 범위 안에 있어 범위 검사만으로
후보를 고를 수 없다. 다른 세 손가락 매핑은 기존값으로 유지했다.

| 뿌리→끝 모델 관절에 넣은 ID | 이전 접촉 자세의 끝패드–엄지 하우징 상자 간 최소 거리 |
|---|---:|
| 기존 9,10,11,12 | 61.42mm |
| 12,10,11,9 | 13.30mm |
| 완전 역순 12,11,10,9 | 34.79mm |

`12,10,11,9` 후보가 이번 측면과 이전 접촉 형태에 더 가까웠다. 그러나13mm는
실제 측정값이 아니며, 아직 접촉 재현에 성공한 것도 아니다. 이 수치는 **끝패드와
엄지 하우징**의 모델 상자 거리에 한정된다. 중지의 다른 부품이 접촉하는 경우,
엄지 매핑 오차, 형상 오차는 별도 문제다. 거리를0으로 만들기 위한 피팅은 하지 않았다.

`motor_order_comparison.jpg`: 네 자세 × 세 대표 후보의 정적 모델 그림.
`overlay_0_1.png`: 기존 임시 손바닥 등록을 유지한 후보 투영.
마커 IPPE 잔차는0.278px지만, 이것은 마커 자체의 재투영 오차이며 손 전체 등록
정확도가 아니다. CAD와 실물 사이 잔차는 남는다. `analysis.json`에24가지 결과,
원본 해시, 실제 각도, 관절 범위 검사와 모델 좌표를 저장했다.
