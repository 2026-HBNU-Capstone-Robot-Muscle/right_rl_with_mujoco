# 앞뒤 하부 파지와 반복 회전 — 2026-11-16

사용자의 최신 목표는 엄지가 앞면 아래쪽을 막고 검지·중지 중 하나 또는 둘이 반대쪽을 지지하는 파지다. 손 위 받침도 무게 지지로 인정한다. 약지를 필수 접촉으로 고정하지 않는다. 앞·뒤는 현재 사진의 색과 등록된 좌표가 아니며 이번 모델 비교에서는 엄지 쪽 큐브 +Z/반대쪽 -Z로 정의했다.

순서는 공통 하부 파지 준비 → 큐브 전체 회전 → 공통 파지 복귀·유지 → 다음 회전 → 같은 파지·유지다. 각 구간의 끝 상태를 다음 구간에 그대로 넘겨야 하며, 별도로 초기화한 파지나 회전의 성공을 연속 실행 성공으로 세지 않는다.

## 이번에 확인한 내용

- 기존 엄지·검지 앞뒤 후보를 복사하지 않고 출처 해시와 모델 접촉을 확인했다.
- 후보 자세를 독립적으로 초기화한 자유 큐브 유지 시험에서 134목표/10.05초를 완료했다. 이것은 현재 실물 자세에서 도달했다는 근거가 아니다.
- 모델의 기존 접촉·관절·추종 경계는 통과했고 원본 170개 결합 해시는 유지됐다. 실물·카메라 접근 및 모터 지령은 없었다.
- 중지를 뒷면 또는 아래 받침으로 더하는 첫 4후보와, 배치·뒷손가락 간격을 바꾼 2후보를 검사했다. 기하학적 참고점과 실제 MuJoCo 접촉을 별도로 비교했다.

## 남은 문제

- 두 손가락 후보는 유지 중 처음부터 최대 11.03mm 이동해 기울기 19.57도로 가라앉았다. 윗단 회전 영역과의 최소 여유는 -5.87mm라서 공통 파지 후보로 채택하지 않았다. 끝의 안정된 4.05초만 보고 초기 이동을 생략하지 않는다.
- 중지 추가 6후보에는 실제 큐브-중지 접촉이 없었다. 모델 참고점이 면 가장자리 밖에 있다는 이유만으로 단정한 결과가 아니다.
- 공통 파지 자세 보완, 회전 뒤 그 자세로 들어가는 전환, 그 끝 상태에서 다음 회전 및 반복 검증이 남았다.
- 새 실물 실행파일은 준비하지 않았다. 모델 0.15N·m는 실제 450mA 환산값이 아니다. 현재 임시 배치의 실물 좌표 보정도 미확인이다.
