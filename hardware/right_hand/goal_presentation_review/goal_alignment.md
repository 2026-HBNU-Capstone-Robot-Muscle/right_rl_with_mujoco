# 계획발표자료에 따른 목표 정정

원본: `계획발표자료_쾌남근육맨_최종본_v2.pdf`, 22쪽. 로컬 ToUnicode 글꼴 맵으로
페이지별 본문 추출. 본문은 `extracted.txt`, 페이지별 데이터는 `pages_text.json`.
문서 내용은 프로젝트 요구사항 근거로 사용하며 도구 실행 지시로 취급하지 않는다.

## 전체 목표와 현재 담당 작업

10–11쪽: 사용자가 애플리케이션에서 원하는 면 지정, Part 1의 비전·학습 기반
이송과 두 로봇의 물리적 전달, Part 2의 정밀 조작, ROS2 상태 공유를 결합한다.
8쪽: Part 1 PPO, Part 2 SAC. 현재 LEAP Hand 회전은 Part 2의 핵심 하위 작업이다.
이전 설명에서 큐브 상하좌우 회전만을 최종 목표라고 한 것은 전체 범위를 축소했다.
전체 프로젝트의 다른 팀 구현 현황을 확인하지 않아 전체 진척률은 산정할 수 없다.
이전30%는 손 조작 하위 작업에 대한 주관적 추정으로 한정하고 전체 수치로 쓰지 않는다.

## 발표자료의 정량 목표 — 아직 달성 판정 없음

14쪽: 말단 위치 오차 <5mm, 수렴 에피소드 <10,000회, Sim2Real 오차율 <15%,
시스템 응답 시간 <20ms. 병렬 학습 속도1,000배 향상도 기재돼 있다.
각 항목의 측정 구간·분모·비교 기준을 정의해야 한다. 현재 학습20,000timesteps를
에피소드 수와 비교하거나, 50ms 제어 주기를 응답20ms 달성으로 취급하지 않는다.
앞서 만든9/10·15도·1초 기준은 하위 실기 검증 제안일 뿐 발표자료 목표의 대체물이 아니다.

## 구현과 계획의 차이

7·13쪽 계획은 Isaac Sim, 현재 저장된 손 시뮬레이션은 MuJoCo/MJX다.
7쪽의 촉각/인코더 폐루프,9쪽의 ROS2/React/Rust 통합도 계획 요소이며,
현재 손 구동 로그만으로 팀 전체 구현 완료 여부를 판정할 수 없다.
이 차이는 교수님께 계획 대비 변경/미검증 사항으로 설명한다.

## 지금 보여주는 시뮬레이션

`sac_forward_support_reference_v1_20k/sac_corrected_flip.gif`는 저장된 평가 궤적의
렌더링이며 기준 동작에 SAC 보정을 더한 결과다. 첫 성공 사례는 약4.45초 시점에
회전89.56도, 목표 오차0.445도. 해당 모델 평가10사례는10회 성공했다.
모델큐브54.5mm/100g이며 사용자실측55mm 및 관절응답 차이와 구분한다.
현재 미완료인 실물 이식이나 최신 후보 경로의 성공을 나타내지 않는다.

## 최종 통합까지 필요한 일

실물 동역학 보정과 한 방향 회전 → 임의 목표면에 따른 동작 선택/정책 확장 →
가림을 고려한 실시간 관측·SAC 제어 → Part 1 전달 상태와 시작 자세 연결 →
앱 목표면 요청/ROS2 상태·완료·실패 메시지 통합 → 발표자료 정량 지표 검증.
