# 엄지만 추가로 닫는 모델 비교

사용자 제안: 사진 같은 하부 파지에서 엄지를 더 밀어 반대편 받침에 고정하면 되지 않느냐는 것이다. 다른 손가락의 지령을 바꾸지 않는 비교를 먼저 수행했다. 관절과 큐브의 동역학은 모두 자유롭게 진행했고 다른 손가락의 위치를 강제로 고정하지 않았다.

맞은편 중지 접촉이 있는 별도 모델 파지에서, 엄지 추가 닫기 가정0/0.4/0.8N의 최종 엄지 법선 접촉력은 각각 약1.453/1.649/1.808N이었다.0.8N 추가 닫기 가정에서 큐브 이동0.349mm·자세 변화0.534도로 유지됐고 마지막4050개1ms 상태의 엄지 하중·전체 손 지지·윗단 공간 조건을 통과했다. 이 수치는 모델의 계산값이며 실제450mA나 실물 힘으로 환산하지 않는다. 압박 증가와 무하중 유지가 확인된 것이며 추가 외부 하중에 대한 강성을 새로 측정한 것은 아니다.

초기 배치부터3015목표로 도달한 첫 파지에서도 엄지 접촉 목표까지 접근한 뒤 추가 닫기를 비교했다. 세 조건에서 지지 자체는 계속됐으나 엄지 접촉력은 약0.004~0.005N으로 작아 엄지 하중0.1N 진단은 미달이었다. 그 상태의 약지는 벌려져 있고 다른 손가락의 맞은편 접촉도 위 별도 파지와 다르므로, 이 결과로 사용자의 사진 파지가 불가능하다고 결론내리지 않는다. 지지 유지 실패와 엄지 압박 형성 미달도 구분한다.

모든 실제 모델 이동은2틱/75ms와 기존 관절·추종·충돌·큐브 이탈 기준을 유지했다. 다른12관절의 지령은 원래 소스와 bit 단위로 같았다. 물리 장치를 열거나 목표를 전송하지 않았다. 사진은 모델 손 좌표계에 정밀 등록되지 않았으므로 어느 시험도 사진 자세의 정확한 재구성으로 부르지 않는다.

다음에는 사진의 큐브 배치와 실제 맞은편 받침을 참고해, 그 받침을 유지한 엄지 추가 닫기를 우선 검토한다. 엄지 압박을 유지하는 것과 다음90도 회전의 접촉 전환은 구분한다. 새 SAC 학습은0스텝이다.
