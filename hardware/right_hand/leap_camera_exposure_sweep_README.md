# 카메라 밝기와 마커 읽기 자동 비교

모터 전원을 끄고 실행하는 **카메라 전용 검사**다. 서보 포트·목표·토크·SAC를 사용하지 않는다. 카메라의 현재 설정과 더 어두운 노출 설정을 비교해 원본 사진을 저장하고, 종료할 때 원래 카메라 설정 복원을 요청하고 읽은 값을 기록한다. 새 카메라 설정이나 좌표 변환을 제어 프로그램에 설치하지 않는다.

1. 다른 카메라/모터 프로그램을 닫고 **모터 전원을 끈다**. 로봇 손가락 모양을 바꾸지 않는다.
2. 큐브를 **손 밖의 책상 위**, 손바닥 가까이에 둔다. 초록 중심 ID5 면을 카메라 쪽으로 향하게 한다.
3. 카메라에 **손바닥 ID40과 큐브 ID5가 함께** 들어오게 한다. 두 마커가 작거나 흐리면 카메라 각도·거리를 조절한다. 반사광은 가려도 된다. 손목 ID41은 이번 검사 대상이 아니다.
4. **터미널 또는 카메라 창에서 SPACE 한 번** 누르고 약15~30초 동안 카메라·큐브를 그대로 둔다. 밝기 변화는 자동이다. Q로 취소할 수 있다.
5. 자동 종료되면 `했어`만 알려주면 된다. `camera_exposure_sweep_날짜_시간/`에 각 설정의 원본 사진·노출 읽은 값·ID 해독 결과·복원 결과가 저장된다. 설정을 지원하지 않거나 마커가 끝내 읽히지 않아도 진단 자료를 남기므로 바로 반복하지 않는다.

최근 접촉 촬영은 정상 저장됐지만 조사한200프레임에서 손바닥 ID40이 해독되지 않았다. 수동 테두리로 계산한 위치는 관측된 정지 상태와 맞지 않아 새 회전 목표의 근거로 사용하지 않았다. 이 검사는 영상 위치 추정의 입력을 개선하기 위한 것이며 재촬영된 파지 동작이나 회전 성공 시험이 아니다.

원래 카메라 값은 자동 모드와 노출 모두 저장한다. 지원하지 않는 setter/읽은 값은 성공 설정으로 취급하지 않는다. 창/캡처/설정 처리는 별도 프로세스 안에서 실행되고 시작10초·측정45초 제한이 있다. 드라이버가 응답하지 않아 프로세스를 강제 종료하면 복원 확인을 하지 못할 수 있으며, 그 경우 결과에 명시한다. 원본 사진에는 안내 글씨를 그려 저장하지 않는다.
