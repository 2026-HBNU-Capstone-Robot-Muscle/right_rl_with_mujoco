# 손가락 각도 보정 실행

실행 파일: `leap_manual_grasp_teach.cmd`

방금 실행한 자연 홈 파지의 같은 목표까지만 진행한다. 자동 열기와 회전은 없다. 진행 숫자는 현재 빈손 자세에 따라 달라지므로1710이라는 숫자 대신 프로그램의 단계 문구를 따른다.

1. 큐브를 손과 카메라 밖에 두고 첫SPACE. 현재 빈손 자세를 읽고 준비 자세로 이동한다.
2. PLACE가 뜨면 초록 위, 주황 손목ID41 쪽으로 자연스럽게 놓는다. 손을 뗀 뒤 두 번째SPACE로 같은 파지까지 이동한다.
3. `[파지 완료 / 자동 열기 없음]`에서 큐브를 아래에서 받치고 세 번째SPACE. 이때는 손가락 각도를 아직 바꾸지 않는다.
4. `[토크OFF 보정]`이 나타나면 원하는 손가락 각도만 천천히 바꾼다. 큐브는 같은 곳에서 받치고,5V 전원과USB는 연결한 채 둔다. 모터 힘만 꺼져 있다.
5. 보정한 모양을 유지하면서 네 번째SPACE. 새 사진 앞뒤로 관절값을 읽고, 각도가 움직였으면 다시 저장을 안내한다.

저장 뒤에도 모터 힘은OFF다. 자동으로 다시 켜지지 않는다. 새 각도는 먼저 모델에서 검토하므로 모터 프로그램이나 위자드에서 토크를 따로 켜지 않는다. 새 목표를 미리 넣지 않으면 보정 전 목표로 돌아가려 할 수 있다.

저장 위치는 `manual_grasp_teach_날짜_시간` 폴더와 `leap_manual_grasp_teach_result.json`이다. 완성되면 채팅에 했어라고 알려주면 된다. 로그를 복사할 필요는 없다. 사람이 받친 상태와 모터OFF 때의 처짐을 포함한 자료이며 자동 파지 성공이나SAC 학습 완료로 표시하지 않는다.
