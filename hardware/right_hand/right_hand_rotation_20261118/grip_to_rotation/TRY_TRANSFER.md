## 이전 받침 관찰의 상세

받침까지만 실행: 저장소 루트의 `leap_grip_transfer_only.cmd`.

큐브를 받치고 다른 제어 실행창을 정상 종료해 토크 OFF로 만든 뒤 실행한다. 기존 파지 위치에 큐브를 놓고 손을 떼고 SPACE로 시작한다. 확정 파지 확인 안내에서 SPACE, 엄지 후퇴 뒤 지지 확인 안내에서 SPACE를 누르면 검지·중지 받침 자세로 이동해 계속 유지한다. 마지막에는 큐브를 받친 뒤 SPACE로 종료한다. 움직이는 도중 SPACE/Q/Esc는 중단/OFF다.

이번 실행의 범위는 **확정 파지 → 기존 엄지 후퇴 → 방금 기록한 검지·중지 받침 → 유지**다. 여기서 큐브가 엄지 쪽으로 이동해 다음 가로 회전의 시작 자리에 놓일 수 있는지 관찰한다. 실제 이송과 회전 시작 배치는 아직 확인하지 않았으며, 전체 회전 구간은 현재 실행파일에서 진행하지 않는다. 확정 파지 G 및 성공했던 회전→G 실행파일은 그대로 보존했다.

2026-11-18 08:52 기록의 두 관절 읽기 차이는 0틱, 모터 쓰기 0회다. 검지·중지 ID5~12만 토크 ON이었으므로 이 여덟 관절의 측정값만 가져왔다. 토크 OFF였던 엄지·약지의 전체 각도를 새 적재 목표로 사용하지 않았다. 엄지는 기존 후퇴 기록, 약지는 기존 G 목표를 쓴다.

측정값은 원본에 보존했고 실행 제안에서 기존 범위 안쪽으로만 보정했다: ID7 3291→3276, ID8 1816→1848, ID12 1833→1848틱. 450mA, 기존 PID, 목표 간격 최대 2틱, 75ms 및 상태·추종·통신 중단 검사를 유지했다. 이 경유 자세의 성공은 아직 실물에서 확인하지 않았다.

소프트웨어 검사는 가상 버스에서 9개 통과했다. 제한된 관찰 실행에 전체 회전이 섞이지 않는지, 단계 확인 전 목표 유지, 이상 시 중단/OFF·설정 복구, 출처 변경 거부를 확인했다. 모델 명목 진단에서 새 손가락끼리의 겹침은 기준보다 증가하지 않았고 추종 중단도 없었다. 다만 받침 프록시와 손가락 뿌리 사이 약 5.06mm 겹침이 나타나므로 전체 모델 안전 검사 통과로 기록하지 않는다. 같은 모델에 방금 읽은 실제 원본 각도를 넣어도 검지 7.34mm·중지 6.15mm의 받침 프록시 겹침이 재현된다. 실제 받침과 프록시의 일치는 미검증이며, 이 수치를 실제 충돌이나 무충돌의 증거로 단정하지 않는다. 비교는 `measured_reference_geometry.json`, 새 경로 진단은 `model_review.json`에 보존했다.
