# 세로 회전 후 확정 파지 복귀만 확인

실행파일은 루트의 **`leap_vertical_return.cmd`**다. 앞서 완료한 세로 회전을 반복하지 않고 복귀 구간만 따로 확인한다.

1. 큐브를 손 밖에 두고 **빈손으로** 파일을 실행해 SPACE를 누른다. 먼저 세로 회전 끝 자세로 천천히 준비한다.
2. PLACE 안내에서 **방금 세로 회전이 끝났을 때와 같은 자리**에 큐브를 놓고 손을 뗀 뒤 SPACE를 누른다. 들어가지 않으면 억지로 끼우지 말고 Q로 종료한다. 위치 참고는 [과거 세로 회전 끝 사진](../../../loaded_repeat_20261026_170932_163649/cube_after_turn.jpg)이며 색/마커 재부착을 요구하는 뜻은 아니다.
3. 손바닥 쪽 이송 → **12:11에 새로 기록한 받침 자세** → 확인SPACE → 중지만 비우기 → 확인SPACE → 중지는 유지하며 엄지·검지·약지를 기존 밀기 시작 자세로 정렬/엄지로 중지 방향 밀기 → **큐브가 검지·중지 사이로 옮겨졌는지 확인SPACE** → 끝마디/하부 받침 준비 → 확인SPACE → 아래를 받쳐 올리기 → 위치 확인SPACE → 기존 확정 G로 닫기/유지 순서다. 큐브가 검지 쪽에만 남으면 다음 파지를 진행하지 말고 받친 뒤 Q로 종료한다.
4. 마지막 파지에서는 큐브를 받친 뒤 SPACE로 종료/OFF한다. 움직이는 중 SPACE/Q/Esc는 중단/OFF다.

11:43 실행에서는 사용자가 확정 파지를 닫는 도중 직접 중단했다. 기계 오류는 기록되지 않았지만, 큐브가 검지 쪽에 치우친다는 관찰이 있었다. 이전 복귀안에는 가로 복귀에서 쓰던 엄지 밀기가 빠져 있었다. 원본 실행 결과와 이전 후보는 보존했다.

수정 경로는 총3179목표다. 현재 세로 회전 끝 목표에서 과거 적재 이송의 작은 옆 여유(ID6−8/ID14+8틱)를4목표로 맞춘다. 이어서 2026-10-28 실물 실행과 목표가 일치한600목표 이송을 쓴다. 그 뒤 새로 기록한 받침 자세로266목표 이동하고 첫 확인을 기다린다. 이어 중지만 비우는101목표와 기존 밀기 시작 자세로 맞추는266목표를 연결한다. 마지막1942목표는 10:23 가로 실물 성공 경로에서 **엄지 밀기부터** 끝마디 준비, 중지 뿌리1880틱 선행, 기존 확정 G까지 그대로 가져온다. 이 출처가 새 세로 연결에서의 큐브 이동까지 인증하는 것은 아니다. 엄지 밀기 뒤 실제 중심 위치를 확인하고 진행한다.

새 받침 목표는 `taught_palm_121158.json`에 있다. 현재16개 토크ON 상태에서 PING/READ만 수행했으며 두 번 읽은 실제 값 차이는0틱,목표와 실제 차이는 최대6틱이었다. 실제값과 유지 목표는 따로 보존하고 **유지 목표**를 사용한다. 모터 쓰기/토크 변경은 없었다. 이후 중지 비우기에서는 엄지·검지·약지를 이 새 값으로 유지한다. 다음 밀기 준비에서 이 세 손가락도 기존 밀기 시작 값으로 정렬한다. 확정 G 자체는 바꾸지 않는다.

모든 목표는 현재 범위 안이고 끝 G는 불변이다. 450mA/기존PID/최대2틱/75ms/전체ON500초 및 상태·전류·전압·추종·진행·읽기 중단 기준을 유지한다. 중간에 토크 OFF나 상태 초기화를 하지 않는다. 관절 범위 확대와 형상 삭제는 없다.

소프트웨어11검사 통과: 빈손 준비/배치 확인,기록 이송600목표와 가로 성공 꼬리1942목표 보존,첫 확인 자세와 새 기록값 일치,중지 단독 비우기,엄지 밀기 뒤 중심 확인 대기,확인 대기 중 상태 감시,이상 시 후속 파지 차단/OFF·설정복구,출처·2틱·범위·시간을 확인했다. 정적 모델에서는 새로 기록한 자세 자체에 약지와 옛 받침 형상의 겹침이 최대7.41mm 나온다. 이동 중 이 기록 자세 및 기존 경로보다 더 깊은 겹침이나 새 손가락 간 겹침은 없지만,현재 실물 받침과 모델이 일치함을 확인한 것은 아니다. 형상/기준은 그대로 보존했다. 큐브 동역학이나 수정 경로의 실물 성공을 뜻하지 않는다. 상세는 `static_review.json`이다.

실행 결과는 `vertical_return_trial_날짜_시각/`에 저장된다. 확인할 내용은 **세로 끝에서 큐브를 떨어뜨리거나 끼우지 않고 현재 확정 파지 G로 돌아오는지**다. 이것을 확인한 다음 앞쪽 세로 회전과 한 실행으로 연결한다.
