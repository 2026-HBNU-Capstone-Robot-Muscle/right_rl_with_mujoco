# 중지 안쪽 관절의 ID 구분 — 모터 구동 없음

07:20 촬영은 완료했다. 끝패드가 굽혀진 동안 가장 크게 변한 값은 ID9(+9.49°)였다.
기존 `ID12=끝관절` 가정을 그대로 적용할 수 없다. 현재 오프라인 후보는
뿌리→끝 순서 `[12,10,11,9]`와 `[12,11,10,9]`이며, 아직 확정하지 않았다.
이 검사는 같은 사진 재촬영이 아니라 **끝에서 두 번째 굽힘 관절**을 움직여
남은 ID10/11의 역할을 구분하는 관측이다. 다른 손가락의 순서는 바꾸지 않는다.

1. 다른 모터 프로그램을 닫고 큐브를 치운다. 현재 자세에서 USB와 모터 전원을
   연결하되 토크는 OFF. 카메라는 중지 전체가 보이는 측면에 그대로 고정한다.
2. `leap_middle_joint_order_readonly.cmd` 실행 후 **첫 SPACE**로 현재 자세 저장.
3. `BASELINE SAVED`가 나오면 **모터 전원을 끈다.** 중지 끝에서 두 번째로
   굽혀지는 관절을 손바닥 쪽으로 약10~15도만 움직인다.
   **끝의 고무패드와 바로 아래 모터 하우징을 함께 움직이고**, 둘 사이의 각도는
   그대로 둔다. 그 아래쪽 마디를 받쳐 뿌리까지 같이 움직이지 않게 한다.
   지난번처럼 끝패드만 굽히는 동작은 아니다. 잘 움직이지 않으면 힘주지 말고 Q.
4. 모터 전원을 다시 연결한 뒤 손을 떼고 **두 번째 SPACE**. 저장 완료까지 고정.

한 창에서 끝난다. 프로그램은 PING/READ만 하며 토크·목표·게인·영점을 쓰지 않는다.
토크 ON이나 불완전한 읽기가 발견되면 측정을 종료한다. 실제 관절 ID를 미리
가정하지 않고 변화량을 기록하며, 보정값을 자동 적용하지 않는다.
