# 세로 회전 후 엄지 밀기 없이 확정 파지로 복귀

2026-11-24 최신: **시작 SPACE 한 번 이후 중간 확인 입력 없이 회전 → 파지 복귀 → G 유지까지 자동 진행한다.** 각 구간 끝의 상태 점검과 기존 중단 기준은 유지한다. 이동 중 SPACE/Q/Esc는 계속 진행 버튼이 아니라 중단/OFF다. 수정한 자동 연결의 실물 확인은 남아 있다.

2026-11-23 사용자 요청으로 **엄지로 큐브를 약지 쪽으로 미는 구간과 그 직후 확인 단계를 제거했다.** 낮은 받침에서 기록된 엄지 후퇴 자세로 직접 연결한다. 수정한 연결의 실물 확인은 남아 있다.

실행파일: [leap_vertical_direct_grip.cmd](../../../leap_vertical_direct_grip.cmd). 이전 실행창은 정상 종료하고 새로 연다.

1. 큐브와 손을 준비하고 손을 뗀 뒤 실행창에서 SPACE 한 번. 시작은 범위 초과분 안쪽 복귀 → 엄지 선행 → 끝마디 준비 → 확정 파지 G다.
2. 기존 세로 회전 후 파지 복귀로 자동 진행한다. 손으로 큐브를 재배치하지 않는다.
3. 엄지·약지 목표를 유지하며 검지·중지를 낮은 받침 자세로 맞춘 뒤 **엄지를 바로 후퇴**시킨다. 후퇴 중 다른 12관절 목표는 유지한다.
4. 검지·중지는 유지하며 엄지를 먼저 파지 위치로 내리고 약지는 함께 비킨다.
5. **검지·중지 1번 → 2번 → 기존 G**로 자동 진행한다. 이 세 구간에서 엄지·약지는 기존 G 목표를 유지한다.
6. 최종 G에서 입력 없이 계속 유지한다. 큐브를 받친 뒤 SPACE로 종료/OFF한다. 이동 중 SPACE/Q/Esc는 중단/OFF다.

전체 실행·최종 유지의 시간 제한은 없다. 전류 450mA, 기존 PID, 최대 2틱/75ms와 전압·온도·추종·진행·유지 관절·통신 이상 중단은 유지한다. 구간 경계의 1목표 상태 점검은 남아 있으며 사용자 확인 대기만 제거했다.

후보 5735목표. 기존 세로 3196목표와 낮은 받침 523목표까지 동일하다. 엄지 후퇴는 새 시작점에 맞춰 166목표로 연결했다. 이후 엄지 선행·약지 비킴 448 / 1번 622 / 2번 505 / G 275목표는 이전과 같다. 이전 후보와 코드는 before_thumb_push_removal_20261123/에 보존했다. 밀기 기록은 보관 자료이며 실행 경로에는 쓰지 않는다.

검사 결과는 test_output.txt와 operator_trial_manifest.json에 기록한다. 중간 입력 없는 전체 진행, 경계·이동·유지 중 SPACE/Q/Esc 중단, 이상 시 후속 차단/OFF·복구를 검사한다. 이동 목표·속도와 형상은 바꾸지 않아 이전 정적 비교가 그대로 적용된다. 큐브 동역학이나 수정한 자동 연결의 실물 성공을 인증한 결과는 아니다.

결과는 vertical_direct_grip_trial_날짜_시각/에 저장한다. 밀기 없이 후퇴할 때 큐브가 받쳐지는지와 이후 1번 → 2번 → G에서 걸리지 않는지를 확인한다.
