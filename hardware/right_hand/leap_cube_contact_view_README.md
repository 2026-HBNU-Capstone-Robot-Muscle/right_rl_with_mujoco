# 쥔 뒤 손끝 접촉 측면 촬영

이번 큐브 포함 회전 시험은 256개 목표와 마지막 목표까지 실행됐고 OFF·설정 복원도 확인됐다. 저장 영상의 큐브 방향 변화는 작아 원하는 회전 성공으로 보지 않는다. 같은 쥐기 목표를 사용한 빈손 기록과 비교해도 추가 전류는 관절별 중앙값 약 0~8mA 수준이다. 힘 측정이나 접촉 여부 확정은 아니지만, 추가 회전 전에 맞은편 손끝이 큐브에 닿는지 확인할 필요가 있다.

이 명령은 기존 v6 쥐기 경로를 그대로 실행한다. 관절 목표·전류·속도를 변경하지 않고, 동작이 끝난 유지 구간에 촬영 안내만 추가한다. 새 손 모양을 손으로 만들 필요가 없다.

```powershell
& "C:\Users\김준서\Documents\Codex\2026-09-23\files-mentioned-by-the-user-leap\outputs\leap_cube_contact_view.cmd"
```

1. 큐브를 빼고 시작한다. 기존처럼 SPACE 시작 → 약지 끝이 손바닥에서 떨어진 것을 확인하고 SPACE → PLACE 때 큐브 배치 후 손을 빼고 SPACE.
2. **Approach ended / REMOVE CUBE**가 나오면 모터 목표가 유지되고 추가 동작은 없다. 바로 빼지 말고 큐브는 그대로 둔다. 카메라를 엄지 반대쪽 옆면으로 옮겨 **검지·중지 끝과 큐브 사이**가 보이게 5~10초 촬영한다. 카메라나 케이블을 손가락 이동 공간에 넣지 않는다. 마커가 보일 필요는 없다.
3. 큐브를 뺀 뒤 SPACE로 OFF한다. 유지 구간의 기존 90초 제한과 Q/Esc/Ctrl+C 중단은 그대로다.

영상과 각도는 기존 `cube_grasp_trial_날짜_시간/`에 자동 저장된다. 긴 로그를 붙이지 않고 `했어`라고 알려주면 된다. 측면 촬영 구간은 `remove_cube`라는 기존 대기 단계에 기록되므로, 해당 단계 이름만 보고 이미 큐브가 제거됐다고 판단하지 않는다.
