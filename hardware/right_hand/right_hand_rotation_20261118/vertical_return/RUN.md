# 세로 회전 후 확정 파지 복귀만 확인

최신 수정본도 실물 확인됐다. `vertical_return_trial_20261118_123353_142977`은3807/3807목표 완료,최종 G 유지 약5.64초,사용자 성공 확인,정상 종료/OFF·복구가 기록됐다. 최대237mA/최소4.4V/최대추종0.04295rad였다. 아래의 수정본 미검증 문장은 이 실행 이전 기록이다. 다음 결합 시험 안내는 [세로 회전+복귀](../vertical_rotation_return/RUN.md)다.

실행파일은 루트의 **`leap_vertical_return.cmd`**다. 앞서 완료한 세로 회전을 반복하지 않고 복귀 구간만 따로 확인한다.

1. 큐브를 손 밖에 두고 **빈손으로** 파일을 실행해 SPACE를 누른다. 먼저 세로 회전 끝 자세로 천천히 준비한다.
2. PLACE 안내에서 **방금 세로 회전이 끝났을 때와 같은 자리**에 큐브를 놓고 손을 뗀 뒤 SPACE를 누른다. 들어가지 않으면 억지로 끼우지 말고 Q로 종료한다. 위치 참고는 [과거 세로 회전 끝 사진](../../../loaded_repeat_20261026_170932_163649/cube_after_turn.jpg)이며 색/마커 재부착을 요구하는 뜻은 아니다.
3. 손바닥 쪽 이송 → **12:11에기록한 받침 자세** → 확인SPACE → **중지는 그대로 유지**하며 엄지·검지·약지 밀기 준비/엄지로 중지 방향 밀기 → **큐브가 검지·중지 사이로 옮겨졌는지 확인SPACE** → 중지 받침을 유지하며 엄지 후퇴/검지 끝마디 준비 → 확인SPACE → 검지·중지를 함께 접어 하부 받침 → 아래를 받쳐 올리기 → 위치 확인SPACE → 기존 확정 G로 닫기/유지 순서다. 큐브가 검지 쪽에만 남으면 다음 파지를 진행하지 말고 받친 뒤 Q로 종료한다.
4. 마지막 파지에서는 큐브를 받친 뒤 SPACE로 종료/OFF한다. 움직이는 중 SPACE/Q/Esc는 중단/OFF다.

12:17 실행 `vertical_return_trial_20261118_121745_804109`은3909/3909목표 완료,최종 G 유지 약7.53초,사용자 큐브 복귀 성공 확인,정상 종료/OFF·설정복구까지 기록됐다. 최대 전류171mA,최소 전압4.8V,최대 추종 오차0.03068rad였다. 이 성공 버전은 `successful_with_middle_clear_121745/`에 보존했다. 그 뒤 사용자 요청으로 불필요한 중지 단독 후퇴를 제거했다. **수정본까지 실물 성공한 것으로 확대하지 않는다.** 세로 회전과 복귀를 한 실행으로 연결한 검증도 아직 아니다.

수정 경로는 총3078목표다. 작은 시작 여유 정렬4 → 과거 적재 이송600 → 기록한 받침266 → 엄지 밀기 준비266 → 엄지 밀기95 → 엄지 후퇴/검지 준비591 → 검지·중지 하부 받침330 → 기존 아래 밀기/확정 G 마무리926목표다. 엄지 준비/밀기/후퇴 동안 중지 네 관절은 기록값3159/2091/1938/2004틱(ID9/10/11/12)으로 유지한다. 다른12관절의 밀기/후퇴 목표는 기존 성공 경로와 같다. 별도의 중지 비움101목표 및 뿌리 선행16목표는 없앴고,엄지가 빠진 뒤에만 검지·중지 하부 받침으로 이어진다. 마지막926목표와 끝 G는 그대로다.

새 받침 목표는 `taught_palm_121158.json`에 있다. 당시16개 토크ON 상태에서 PING/READ만 수행했으며 두 번 읽은 실제 값 차이는0틱,목표와 실제 차이는 최대6틱이었다. 실제값과 유지 목표는 따로 보존하고 **유지 목표**를 사용한다. 모터 쓰기/토크 변경은 없었다. 받침 확인 후 중지를 뒤로 빼지 않고 엄지 밀기를 준비한다. 확정 G 자체는 바꾸지 않는다.

모든 목표는 현재 범위 안이고 끝 G는 불변이다. 450mA/기존PID/최대2틱/75ms/전체ON500초 및 상태·전류·전압·추종·진행·읽기 중단 기준을 유지한다. 중간에 토크 OFF나 상태 초기화를 하지 않는다. 관절 범위 확대와 형상 삭제는 없다.

소프트웨어11검사 통과: 기록 이송600/마무리926목표 보존,최종 G 일치,엄지 준비부터 후퇴까지 중지 받침 유지,첫 확인 자세 일치,중간OFF 없음,확인 대기/이상 시 후속 차단과 복구,출처·2틱·범위·시간을 확인했다. 정적 모델에서는 기록한 자세 자체에 약지와 옛 받침 형상의 겹침이 최대7.41mm 나온다. 이동 중 이 기록 자세 및 기존 경로보다 더 깊은 겹침이나 새 손가락 간 겹침은 없지만,현재 실물 받침과 모델이 일치함을 확인한 것은 아니다. 형상/기준은 그대로 보존했다. 큐브 동역학이나 수정 경로의 실물 성공을 뜻하지 않는다. 상세는 `static_review.json`이다.

실행 결과는 `vertical_return_trial_날짜_시각/`에 저장된다. 확인할 내용은 **세로 끝에서 큐브를 떨어뜨리거나 끼우지 않고 현재 확정 파지 G로 돌아오는지**다. 이것을 확인한 다음 앞쪽 세로 회전과 한 실행으로 연결한다.
