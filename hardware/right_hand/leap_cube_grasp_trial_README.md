# 큐브를 놓은 뒤 접근하는 시험

이 실행은 02:07에 끝낸 빈손 접근의 **동일한 관절 목표**를 사용한다. 먼저 빈손으로 열린 자세로 돌아가고, 큐브를 놓았다는 SPACE 확인 뒤 천천히 접근한다. 회전이나 SAC 정책은 실행하지 않는다. 큐브가 손가락 사이에 남는지는 새 저장 영상으로 확인해야 한다.

v3에서 초기화 중 닫힌 접근 자세를 먼저 복원하던 경유를 삭제했다. v4는 먼저 약지 PIP(ID15)를 펴고, 실제 각도와 사용자의 접촉 분리 확인을 받은 뒤 엄지와 나머지 손가락을 연다. 이때 중지 뿌리 ID12를 닫힌 목표2613틱으로 올리지 않는다. 열린 목표는2472틱이다. 열린 자세에서1초간 읽기만 하며 정착을 확인한 뒤 PLACE를 표시한다.

1. 다른 모터 프로그램은 닫고 USB·모터 전원을 연결한다. 큐브는 빼고 손 모양은 그대로 둔다. 카메라는 손 전체가 보이게 하고, 아래에는 떨어지는 큐브를 받을 패드를 둔다.
2. **터미널에서 첫 SPACE**: 실제 OFF 각도를 읽고 경로를 검사한 뒤, 빈손 복귀/열기를 실행한다. 이때 큐브를 올리지 않는다.
3. **RING RELEASE CHECK**가 나오면 손을 대지 말고 약지 끝이 손바닥에서 떨어졌는지 본다. 떨어졌을 때 **터미널 두 번째 SPACE**로 확인하면 나머지 빈손 열기가 진행된다. 아직 닿아 있거나 확인할 수 없으면 Q로 중단한다. 큐브는 계속 빼 둔다.
4. **PLACE CUBE**가 나오면 ID40 옆 손바닥과 손가락 사이에 큐브를 놓는다. 초록 중심면 위, 주황 중심면 카메라 쪽. 손으로 계속 받쳐야 하거나 끼워 넣어야 하면 Q로 중단한다.
5. 사람 손을 빼고 **터미널에서 세 번째 SPACE**: 배치 사진을 저장하고 3초 뒤 약16초 동안 접근한다. 움직이는 동안 큐브를 손으로 보정하지 않는다.
6. 접근이 끝나고 **REMOVE CUBE**가 나오면 조심히 큐브를 뺀 뒤 **터미널에서 네 번째 SPACE**: 토크 OFF와 설정 복원을 확인한다. Q/Esc/Ctrl+C는 중단이다.

카메라와 관절 자료는 `cube_grasp_trial_날짜_시간/`에 자동 저장된다. `open_before_cube.jpg`, `cube_before_approach.jpg`, `cube_after_approach.jpg` 및 단계별 원본 프레임을 남긴다. ID40이 가려져도 촬영할 수 있다. 프로그램이 정상 종료해도 파지/뒤집기 성공으로 자동 표시하지 않는다.

예전 ON/OFF 기록과의 일치를 시작 조건으로 요구하지 않는다. 현재 각도에서 열린/닫힌 검토 목표 중 하나까지 각 관절512틱(45°) 이내인 시작을 검사 대상으로 접수한다. 실제 계획은 닫힌 목표를 경유하지 않고 빈손 열기를 수행하며, 대기 제외 전체 목표/정착 시간은 계획 단계에서50초 이내여야 한다. 이 접수 조건은 경로 승인과 다르다. 실제 실행마다 세 번의 안정 OFF 읽기와 ±4틱 67개 경로 사례, gain0.5/1/1.5 동역학 검사를 다시 통과해야 한다. 토크 OFF 처짐으로 모델 범위를 조금 벗어난 경우, 기존 초과가0.06rad 이하이고 첫 **빈손 복귀** 단계에서 관절별로 단조롭게 감소하여0이 되는 경우만 접수한다. 원래 모델의 관절/제어 범위는 수정하지 않는다. 큐브를 놓은 뒤에는 이 예외를 허용하지 않는다.

초기의 모델 겹침은 실제 눌린 깊이의 측정값이 아니다. v4는2mm라는 단일 수치 대신 **짧은 분리 동작의 검증 결과**를 요구한다. 지정된3개 약지 끝/손바닥 초기 접촉만 허용하며, 각 깊이가 단조 감소하고 약지 PIP64틱(5.625°) 이내/40개 목표 안에 완전히 분리되어야 한다. 동역학은 초기 깊이를 넘지 않고 초기 유지 포함2.5초 내에 분리되어야 한다. 새 접촉/깊어짐/이후 재접촉은 계속 거부한다. 분리 위치는67개 시작 사례 중 가장 보수적인 값보다16틱 더 편 실제 각도로 확인하고, 사람의 관찰 확인 전에는 엄지·나머지 열기를 보내지 않는다. 이 조건은 접촉 중인 관절을 더 누르거나 깊이 상한을 임의로 올리는 방식과 다르다.

450mA/기존 PID, 2틱 이하 목표 간격, 처리 포함50ms 주기, 추종0.18rad·전류·전압·읽기 지연 검사와 실패 시 OFF/복원은 유지한다. 55초는 모터 경로의 시간 제한이며, 건강 상태를 읽으며 기다리는 약지 분리 확인과 PLACE는 각각90초 제한이다. SPACE를 누르지 않으면 다음 동작을 보내지 않으며, 실패한 목표를 자동 재전송하지 않는다.

실제 큐브 위치, 케이블 변형, 파지 힘은 완전히 교정되지 않았다. 오프라인 검사는 실물 파지나 회전의 성공 증거가 아니다.
