# 확정 파지 → 세로 회전 → 같은 확정 파지

루트의 [leap_vertical_rotate_grip.cmd](../../../leap_vertical_rotate_grip.cmd)를 실행한다. 실물에서 각각 성공한 세로 회전과 최신 복귀를 한 제어 루프로 연결한 첫 시험이다. 이 결합 실행 자체는 아직 실물 확인 전이다.

1. 큐브를 **확정 파지 자리에서 준비**하고 손을 뗀 뒤 실행창에서 SPACE를 누른다. 종료 후 토크OFF로 처진 관절은 G까지 기존 속도로 먼저 복귀한다. 빈손 배치용 파일이 아니며 PLACE 단계는 없다.
2. 확정 파지 확인 안내에서 SPACE를 누르면 이송/세로 회전이 이어진다. 엄지를 먼저 내린 뒤 검지·중지를 세우는 성공한 순서를 그대로 쓴다.
3. 회전 끝에서 토크를 유지하며 기다린다. **손으로 큐브를 다시 놓지 않고**, 복귀 시작 자리에서 받쳐진 상태면 SPACE로 복귀한다. 자리 불일치/낙하/끼임이면 큐브를 받친 뒤 Q로 종료한다.
4. 복귀 중간에는 별도 확인 대기 없이 기록 받침 → 중지 유지/엄지 밀기 → 엄지 후퇴 → 검지·중지 하부 받침 → 확정 G로 이어진다. 최종 G에서는 계속 유지한다. 큐브를 받친 뒤 SPACE로 종료/OFF한다.

움직이는 중 SPACE/Q/Esc는 중단/OFF다. 기존 단독 실행파일 두 개를 차례로 실행하는 방식과 달리,중간 OFF·포트 재연결·자세 초기화가 없다. 회전 끝 확인은 두 실행에서 큐브 시작 위치가 실제로 이어지는지 보는 단계다. 관절 목표 일치만으로 큐브 위치까지 같다고 가정하지 않는다.

450mA/기존PID/최대2틱/75ms 및 전류·전압·온도·추종·진행·읽기·유지 관절 감시를 그대로 쓴다. 한 실행의 전체 ON500초 제한은 확인 대기와 추종 대기도 포함하며 중간에 타이머를 다시 시작하지 않는다. 확정 G에서의 명목 경로 시간은 약464초다.

12:48 시작 거부는 구동 전 시간계산 단계였으며 모터 명령은 나가지 않았다. 기록된 OFF 처짐 자세에서 G까지277목표/약20.8초가 필요해 전체 명목 시간이484.425초인데,일률적인30초 예약 여유를 더하면서 거부됐다. 시작 예약 여유를10초로 바꾸고 **각 목표 진행 직전 실제 경과시간 + 남은 목표 시간 + 최종 유지5초**가500초 안에 드는지 검사하도록 보완했다. 따라서 이 기록 자세에서 출발하는 가상 실행은 끝까지 통과한다. 하드500초 제한을 늘린 것은 아니며,확인 대기가 길어 남은 동작을 끝낼 수 없으면 다음 목표를 내보내지 않고 종료한다. 더 먼 시작 자세는 초기 시간예산 검사에서 계속 거부된다.

소프트웨어12검사와 장치 없는 실행 검사를 통과했다. 목표열 보존,중지 받침 유지,회전 끝 확인 대기,중간 OFF 없음,이상 시 복귀 미진입/복구,확인 대기에도500초 제한,OFF 시작의 기존 사전 적재 확인,시간·범위·2틱과 출처 변경 거부를 검사했다. 추가로 **이번 OFF 시작값에서 전체 완료** 및 **회전 끝 확인을 오래 지연하면 복귀를 시작하지 않고 복구**하는 경우를 검사했다. 새 동역학 평가나 전체 실물 성공을 뜻하지 않는다. 모델의 옛 받침 형상 불일치는 기존 정적 자료와 함께 보존하며,형상을 제거하지 않았다.
