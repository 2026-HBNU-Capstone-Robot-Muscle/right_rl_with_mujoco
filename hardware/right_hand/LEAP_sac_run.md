# SAC 반영 배포 정책 실행

실행 파일: `leap_sac.cmd`. 현재 배포된 `policy_np.npz`는 PPO 교사와 residual SAC를
증류한 단일 정책이다. 독립 SAC actor를 새로 학습하거나 불러온 것으로 설명하지 않는다.
정책 경로와 SHA256은 매 실행 JSON에 남긴다. 원본 성공 시퀀스는 실행하지 않는다.

## 달라진 동작

- 준비 자세 주변 ±0.05/0.10rad 제한을 없애고 학습의 SAFE_LOWERS/SAFE_UPPERS를 적용한다.
  절대 관절 한계는 유지하고 encoder 목표는 그 안쪽 정수로 반올림한다.
- `q_command + 0.2 * policy_action`을 누적한다. 명령당 최대32틱과 최소50ms 간격을 유지한다.
  nominal 목표 변화 속도 상한은 약56.25°/초이며, 실제 속도는 영상/통신/추종에 따라 낮아진다.
  제한 후 실제로 적용한 action을 다음 관측에 되먹임한다.
- 정책 구간20초. 카메라로 추정한 ID0 면이 위를 향하는 목표를 사용한다.
- 현재 검증된 학습 DEFAULT_POSE로 빈손 준비한다. sequence_flip.py의 첫 자세는 참고자료로
  보존하며 초기상태까지 동시에 교체하지 않는다. 기록 자세를 재생하는 것이 아닌 정책 제어다.
- 550mA/장치 PID 보존, 원래 관절 한계, 전류·온도·전압·추종·통신 watchdog 및 취소 검사를 유지한다.
  시퀀스 파일을 실행해 PID가 바뀌었다면 현재 장치 값을 읽어 출력하고 그대로 보존한다.
- 마커2개/손ID40/3px/신선도200ms/이력3프레임 유지. 무효 영상에서는 마지막 목표를 유지한다.
  단발 RX_TIMEOUT(-3001)은 새 읽기를1회 수행한다(첫 실패100ms 미만,
  전체200ms 이내,10초 내 최대3회 복구 시도). 부분 데이터는 폐기한다.
  지속 입력 단절/통신 실패/장치 오류는 OFF 경로로 끝난다. 목표쓰기나 토크ON을 재전송하지 않는다.

## 사용자 실행

다른 핸드 제어 프로그램을 닫고, 손을 고정·비운 상태로 USB와 모터 전원을 연결한다.
큐브 아래에는 떨어질 때 받을 부드러운 받침을 둔다.

```powershell
& "C:\Users\김준서\Documents\Codex\2026-09-23\files-mentioned-by-the-user-leap\outputs\leap_sac.cmd"
```

1. 카메라 창 SPACE → 3초 카운트다운 → 학습 시작 자세로 빈손 준비.
2. PLACE에서 큐브 배치. 손ID40과 큐브 두 면을 보이게 하고 사람 손을 뺀다.
3. READY에서 SPACE → 정책20초. 이번에는 ±0.10rad를 넘는 큰 동작이 나올 수 있다.
4. REMOVE에서 큐브 제거 후 SPACE → 전체 토크OFF/설정 복원.

Q/Esc/Ctrl+C는 중단. 배치/제거 중에는 정책 명령이 나가지 않는다.
결과는 `leap_sac_result.json`, 시각별 JSON 및 `leap_sac_vision_*` 원본에 저장된다.
구동 후 큐브가 실제로 잡히고 회전했는지, 떨어지거나 걸렸는지도 함께 기록한다.
