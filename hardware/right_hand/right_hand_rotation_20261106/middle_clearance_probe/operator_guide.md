# 중지 공간 확인 동작

기존 파지를 유지한 채 중지만 기록한 굽힘의 절반만큼 접었다 돌아온다. 중지 쪽 윗단 공간과 큐브가 남아 있는지를 촬영하는 실험이다. 엄지 낮추기, 윗단 회전, 완성된 하부 파지 검증은 후속 단계다. 손가락을 직접 만져 보정하는 단계는 없다.

1. 큐브를 손과 카메라 화면 밖에 두고 아래 명령을 실행한다. 손 모양과 받침은 그대로 둔다. 터미널에서 첫 SPACE를 누르면 빈손 준비가 시작된다.
2. `PLACE`가 뜨면 손가락 뿌리 홈에 큐브를 자연스럽게 놓는다. 초록 면이 위, 주황 면이 손목 ID41 쪽이다. 손을 떼도 큐브가 남아 있는 상태에서 두 번째 SPACE를 누른다.
3. 기존 파지 5초 → 중지만 약 3.6초 접기 → 보정 자세 5초 → 중지 복귀 → 자동 OPEN 순서다. OPEN 뒤 큐브를 빼고 세 번째 SPACE를 누르면 OFF와 설정 복구를 확인한다.

```powershell
& "C:\Users\김준서\Documents\Codex\2026-09-23\files-mentioned-by-the-user-leap\outputs\leap_middle_clearance_probe.cmd"
```

동작 시간은 약 4분이며 큐브를 놓고 빼는 시간은 별도다. 동작 중 손가락이나 큐브를 직접 움직이지 않는다. Q, Esc, Ctrl+C로 중단한다. 450mA와 기존 PID, 전압 및 통신·추종 중지 기준을 유지한다.

실행 후 ‘했어’만 알려주면 저장 파일로 확인한다. 결과 포인터는 `leap_middle_clearance_probe_result.json`이며 실제 실행마다 별도 폴더에 영상과 관절값을 남긴다.

## 확인한 범위

빈손 복귀의 정적 201조건 및 동적 9조건, 새 동작의 손 9조건 및 큐브 27조건을 통과했다. 소프트웨어 시험 15개와 장치를 열지 않는 기본 실행을 확인했다. 기존 4틱 이내의 OFF 오차 중심 재사용을 적용해 미세한 처짐 때문에 같은 모델 검사를 매번 다시 실행하지 않도록 했다. 실제 시작값과 토크 ON 때의 4틱 확인, 모든 건강 상태 확인은 유지한다.
