# 뒤쪽 접촉·끝마디 우선 이동 시험

실행: `leap_cycle_tip_first_transfer.cmd`

사용자가 확인한 뒤쪽은 주황 옆면에서 흰 앞면 모서리와 멀어지는 방향이다. 모델에서는3mm 접촉 이동을 가정했다. 실물3mm를 측정하거나 보증한 값은 아니다.

## 달라진 동작

기존 첫 회전 → 중지 윗마디 먼저 펴기 → 엄지 이송 → 뒤쪽 접촉 목표 → 엄지 ID1·중지 ID9 끝마디 먼저 굽히기 → 엄지 ID2·중지 ID11 굽히기 →4.05초 관찰. 끝마디 굽힘에 의해 눌리는 다른 마디의 목표는 조금 풀어 주도록 모델에서 경로를 계산했다. 이 기록을 재생하며 실물에서 모델 힘 센서나 실시간 SAC를 사용하는 것은 아니다.

최대 굽힘을 곧바로 강제하지 않는다. 원래 범위 안의 절반 방향 후보에 목표 압박 제한을 적용했다. 실제 최대 관절값까지 도달했다고 인증하지 않았다.

## 실행

1. 빈손으로 새파일을 실행하고 첫 SPACE로 현재 OFF 자세 검사·준비를 시작한다.
2. PLACE 안내 때 **초록 위·주황 손목 ID41 방향**으로 큐브를 놓고 손을 뗀 뒤 두 번째 SPACE를 누른다.
3. 큐브가 미끄러지거나 떨어지면 Q/Esc/Ctrl+C로 중단한다. 모터 감시만으로 큐브 낙하를 자동 판정하지 않는다.
4. 관찰 종료 안내 때 큐브 아래를 받친 뒤 마지막 SPACE로 토크 OFF하고, 종료 후 큐브를 제거한다.

사진 `cube_tip_first_hold.jpg`, 기존 배치·파지 사진, 영상과 모터 기록은 새 `tip_first_trial_.../`에 자동 저장된다. 따로 촬영하거나 로그 전체를 붙여 넣을 필요는 없다.

## 검증 범위

마찰0.2/0.3 가정 × 모델 구동 응답0.5/1/1.5의6조건에서 처음부터 초기화 없이3110목표를 검사해 기존 구동·간섭·지지 기준을 통과했다. 빈손3조건, 실행기9시험, 경로 제안 모듈4시험과 고정 관절·진행 감시 재생을 통과했다. 동일한 저장 씨드의 빈손201정적/9동적 검증을 상속했고 현재 OFF 자세는 실행 시 다시 검사한다. 원본170개 결합 해시는 실행기 시험에서 확인했다.

450mA·기존 PID·최대2틱/75ms·기존 건강/전압/전류/통신/추종/진행/고정 관절 중단 기준과 승인된 최대500초를 유지한다. 추가 승인값 입력은 없다. 이전64틱 목표 여유 후보는 진행 감시에서 거부돼 보존했으며, 이번40틱 목표 여유는 중단 기준 변경이 아닌 경로 자체의 압박 감소다.

**이번 파일은 제안한 밀기 순서를 확인하는 관찰 시험이다. 지난번 ID15에서 중단한 약지 닫힘, 최종 세 손가락 파지, 다음 회전과 왼손 동작은 포함하지 않는다.** 모델의 큐브 기울기도 남으므로 전체 작업 완료나 왼손 인계 준비 완료로 판정하지 않는다. 실제 저마찰 재료의 계수는 측정하지 않았다.

## 2026-11-13 시작 검사 수정

사용자가 허용한 엄지 끝–검지 뿌리의 기존 초기 모델 겹침만 빈손 복귀에서 분류 예외로 처리했다. 초기 모델 깊이 상한1.75mm(관절 교란 조건 포함) 안에서 초기값보다 깊어지지 않고, OPEN 48목표 이내에 사라져 배치 유지 때0이어야 한다. 형상과 접촉력 계산은 그대로이며 다른 접촉·적재 경로·모터 감시 한도는 유지한다. 최근 저장 자세3개에서 각각201정적/9동적 조건을 검사했다. 같은실행파일을 사용한다. 새실물실행은아직하지않았다.
