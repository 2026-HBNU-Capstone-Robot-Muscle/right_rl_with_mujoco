# 기존 회전 → 엄지 후퇴·끝마디 준비 → 검지·중지 하부 밀기 → 확정 파지

실행파일: 작업 폴더의 `leap_quarter_to_fixed_grip.cmd`.

최신 통신 수정은 기존 실행창을 정상 종료하고 다시 열어야 적용된다. 보통 Sync READ를2개 모터씩 요청하며 전체16개 상태와 기존200ms/재시도율/건강 감시는 유지한다. 현재 열린 예전 실행창에는 자동 반영되지 않는다.

1. 다른 로봇 실행창을 종료하고 **큐브를 손에서 빼 빈손으로 시작**한다. 파일을 열고 손을 뗀 채 SPACE를 누르면 기존 큐브 배치 자세로 이동한다.
2. **PLACE 안내가 나온 뒤** 예전 90도 회전 시험과 같은 자리에 큐브를 놓는다. 손을 떼고 SPACE를 누르면 기존 회전 구간을 실행한다.
3. 회전 뒤 대기에서 큐브가 손에 남아 있는지 확인한다. 손을 뗀 채 SPACE를 누르면 엄지는 유지하고 **중지만 먼저 뺀다**.
4. 중지 후퇴 뒤 큐브가 받쳐져 있고 이동 공간이 생겼으면 SPACE를 누른다. 다른 손가락은 유지하고 **엄지를 기록한 준비 자세로 옮긴 뒤 중지 쪽으로 조금 미는 동작**을 한다.
5. 엄지 밀기 뒤 큐브가 옮겨졌으면 SPACE를 누른다. **엄지를 손목 쪽으로 빼면서 검지·중지 끝마디를 먼저 준비**한다. 다른 검지·중지 마디와 약지는 유지한다.
6. 엄지가 비켰고 큐브가 받쳐져 있으면 SPACE를 누른다. 끝마디 모양을 유지한 채 검지·중지의 다음 마디를 중간까지 접고, 이어 아랫마디와 함께 움직여 **큐브 아래를 받쳐 미는 구간**을 실행한다.
7. 하부 밀기 뒤 큐브가 파지 자리에 옮겨졌으면 SPACE를 누른다. 기존에 확정한 최종 파지 목표로 마무리하고 계속 유지한다.
8. 마지막 `확정 파지 목표 유지 중` 안내가 나오면 실행창을 열어 둔 채 ‘유지 중’이라고 알려주면 된다. 종료할 때는 큐브를 받친 뒤 SPACE를 누른다.

SPACE는 안내된 배치·회전·중지 후퇴·엄지 밀기·끝마디 준비·하부 밀기 대기에서만 다음 단계로 진행한다. 이동 중 SPACE 또는 언제든 Q/Esc를 누르면 중단하고 토크를 끈다. 토크가 켜진 채 손가락을 강제로 맞추지 않는다. 기존 상태 감시에서 중단되면 새 결과 폴더를 확인한다.

기존 회전의 1,417개 목표와 순서를 그대로 사용한다. 엄지 밀기 끝까지 총2,343개 목표도 이전 경로와 같다. 최종 파지 목표는 `right_hand_rotation_20261117/user_measured_grip/reference.json`의 실제 유지 목표와 같다. 새 적재 경로는4,174개 목표이며 최대2틱/75ms,450mA,기존PID와 상태 감시를 사용한다. 단계 사이에 자동OPEN/OFF는 없다. 총 토크ON 한도500초에는 빈손 준비·배치·확인·추종 대기도 포함된다.

사용자가 맞춘 네 중간 자세의 관절값을 역할별로 사용한다. 4번에서는 검지·중지 ID5..12만 사용하고 엄지·약지 값은 가져오지 않는다. 끝마디 ID5/9를 먼저 준비한 뒤 그 모양을 유지하면서 다음 마디와 아랫마디로 옮긴다. 최종 파지에서만 끝마디도 원래 확정 목표로 마무리한다. 전체 손의 측정 자세를 그대로 재생하지 않는다. 뿌리 ID8/12의 범위 밖 실측은 원래 범위 안쪽1848틱으로 조정한 제안이며 다른 관절 한계를 넓히지 않았다.

다음 회전은 아직 포함하지 않은 **단계 확인 시험**이다. 기존 전환은 실물에서 최종 닫기 중 중지의 진행/추종으로 중단됐고 이번에 끝마디와 하부 밀기 순서를 바꿨다. 새 전환의 실제 큐브 이송과 최종 방향·유지는 검증 전이다. 최신 검사 결과는 `tip_first_lower_seat/`,시점 비교는 `tip_first_timing_comparison/`에 보존한다. 전체 모델 조건과 자동 연속 동작의 성공을 보증하지 않는다. 최종 파지 후 방향 오차±5도는 평가 기준이며 이번 실행에서 자동 측정하지 않는다.

실행 결과는 `quarter_fixed_grip_trial_날짜_시간/`에 저장한다. 보조자는 모터 실행을 시작하지 않았으며 사용자 파일 실행과 SPACE로만 시작한다. 모든 변경은 로컬에 있다.
